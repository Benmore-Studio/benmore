A Git warning on a successful history command (for example about an unreadable untracked directory) is not read as output: it cannot become a staged filename or corrupt parsed history. Nonzero Git exits fail with diagnostics; source-saved/history-committed receipts and protected-path checks apply as described here. This does not remove unreadable directories or repair existing history; inspect source sync and resource cleanup separately. A push that answers `history_error: openat .gitignore: permission denied` (source_saved: true) saved the source: restart the app, which repairs that file's permissions, and push again.
