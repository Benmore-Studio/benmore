GitHub sync is refused for an app whose prod or dev app.yaml sets `compliance: hipaa`, or that the platform has recorded as hipaa (the record outlives the key; api(at:"compliance")): github_link / the dashboard link route answer `GitHub sync is not available for apps with compliance: hipaa`, and a push for an app that became hipaa after it was linked switches the mirror off (`enabled: false`, reason in `last_error`: `sync disabled: ...`) instead of pushing. Only the `compliance` key is read. An app.yaml that cannot be read or parsed refuses that push (`GitHub sync needs to check compliance first: ...` in `last_error`) and leaves the mirror on, and refuses a link. Source, seeds and tests would otherwise leave the platform for a subprocessor not covered by a BAA.
