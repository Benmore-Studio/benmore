Successful source mutations through write_file/edit_file/delete_file/feature_install expose history_committed. An already-missing delete is an idempotent no-op. A failed commit after a saved mutation returns an MCP/CLI error with source_saved:true and history_error; the source mutation and requested reload are not rolled back. Inspect the receipt before retrying. create_app preserves its successful creation receipt and reports history_committed:false/history_error if initial history failed, so a retry does not accidentally create another app.
