A mirror that is switched off shows `enabled: false` in github_status, with the reason as text in `last_error`: an ownership transfer, the GitHub account disconnected, the collaborator who linked it removed, the linking account without editor access, or `compliance: hipaa`. A mirror an ownership transfer switched off (whether or not it was running) can be linked again or removed only by the app owner: disconnecting GitHub or a late push result does not change that. Push results update only `last_error` and the pushed sha, and only on a running mirror.
