GitHub sync (hosted platform) - ONE-WAY mirror of an app's per-app git history to a GitHub repository the user owns (personal account or organization). Connect once via OAuth (dashboard → app → Version Control → Connect GitHub), link a repo (created automatically, private by default), and every commit - each write_file/edit_file/delete_file lands as one - pushes automatically ~15s after a burst of edits: the Live instance to `main`, the Sandbox instance to `dev`. One GitHub repo, two branches: dev-vs-live is a diffable, PR-able view. Automated staging excludes designated runtime/secret paths independently of gitignore. Push audits all reachable commits for those paths and refuses contaminated history; this is not a general secret-content scanner. Nothing is ever pulled FROM GitHub - the platform is the source of truth; a diverged remote (someone pushed to GitHub directly) makes the sync fail visibly and force-push is an explicit action.
