JSON numbers passed to compute are native JavaScript numbers, including numbers nested in arrays and objects from a strict_json request. Conversion happens only at the compute boundary: the request and SQL bindings retain their original values. Ordinary compute uses JavaScript IEEE-754 semantics (integers outside Number.isSafeInteger may round; send exact identifiers as strings); non-finite/out-of-range JSON numbers fail before the function runs. Reviewed connector compute retains its stricter exact-number admission check.
