Server-side JS/TS execution via the `run: compute` flow step. Runs a named export from a static/<module>.ts file server-side through embedded goja (Go-native ES engine). Use when an algorithm doesn't fit SQL - iterative math, root-finding, financial pro-formas (IRR, goal-seek), scoring, simulation. The killer property: the SAME module imports CLIENT-side for instant recompute as the user edits AND runs SERVER-side for authoritative gates / cron / webhook handlers - one algorithm, two execution paths, byte-identical math, no fork.
