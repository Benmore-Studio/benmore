A missing whole-reference argument, including one nested in a map or array or naming an absent env value, stops the flow with an unresolved-reference error before compute runs, unless it reads an output of a step the flow has already reached. A query step that matched no row (`steps.x.outputs.first.col`), a step its `if:` skipped (either branch, or a loop that ran zero times) and a key the module did not return arrive as null. A step id that is not in the flow, an unset env value and a request field the caller did not send stop the flow; use an explicit default pipe for those when they are optional. Explicit null, zero, false and empty-string values keep their native types.
