Every script under static/ and src/ (.ts, .tsx, .js, .jsx, .mjs, .cjs, .mts, .cts; not .d.ts) is parsed when it is written and by benmore check, and one that does not parse is refused with file:line:column and the parser message (a duplicate `const`, `await` outside an async function, an unclosed brace). The check parses one file and does not resolve imports, so a missing import still fails at build time; files over 4 MiB are not parsed.
