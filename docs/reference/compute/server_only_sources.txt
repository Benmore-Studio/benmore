A `run: compute` module and every file it imports (relative imports, at any depth) are never served, as source or compiled .js. static/ is served at /static/<path> and from the URL root at /<path>; both answer the same 404 for such a file, also with a trailing slash, a query string or percent-encoding and for HEAD and range requests, and no other spelling of the path returns it. The same holds for all TypeScript and JSX source under static/ (.ts, .tsx, .mts, .cts, .jsx): pages load the compiled /static/<name>.js, which is served under /static/ only. Browser modules that the compute module does not import are served, and a browser module that imports it is served with that code bundled in. If a compute module does not compile, every script in its directory is refused until it does. `pwa.service_worker` cannot name a compute module: /sw.js then serves the generated worker. Keep secrets in env vars (`env.X` in the flow), never in static/. write_file and edit_file (behind benmore push) say so in `next_steps` for such a file (the compute module, a file it imports, or a script beside a compute module that does not compile): it is server-only and /static answers 404 for it.
