Return or await the promise covering the entire fetch and render. Detached asynchronous work, manual calls to the same renderer and other subscriptions are outside this ordering guarantee. A callback that never settles blocks its subscription; the helper does not time out and overlap it. Rejections are logged and release the running slot so a queued refresh can proceed. Unsubscribe cancels pending timers, queued work and future event delivery; it cannot cancel or undo effects of a callback already running. Guard component teardown and identity changes inside that callback when needed. This helper is not an authorization or session boundary.
