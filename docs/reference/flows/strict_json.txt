For a request that must not accept ambiguous JSON, set `strict_json: true` under `on.request`. Before any flow step runs, the runtime requires `Content-Type: application/json`, reads at most 32 KiB, and accepts exactly one JSON object with no duplicate keys at any nesting level. Oversized, malformed, trailing, non-object, wrong-media-type, or duplicate-key requests get a generic 400 with no body echo; so does a query-string field that names a body key (a `verify:` flow binds no query field at all, see api({at:'verify'}) → signed_input). The default is false. The write gate and `benmore check` reject non-boolean values.
