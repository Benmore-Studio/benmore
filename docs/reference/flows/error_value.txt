Inside an `on_error:` handler, `${{ error }}` is the failed step's error as text, for a respond, an INSERT into your own failure table or a notification. It is the same redacted text an app admin sees as step_error: one line, at most 2 KiB, every value the flow can read from the app's env (and every value derived from one) replaced by [redacted] as written and URL-escaped, and credential-shaped text (query strings, bearer tokens, long hex) redacted. When the failed step (or a step nested in a failed if/for_each/parallel block) read request input, `error` is request input too, so sql_dynamic refuses it; bind it with `:name` in `run: sql` or write it as a value. A request field named `error` is replaced by the failure text inside the handler.
