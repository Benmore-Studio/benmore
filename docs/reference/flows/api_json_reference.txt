A run: api step's `json:` may be one `${{ }}` reference instead of a map or list (`json: ${{ steps.build.outputs }}`); the value it names (an object, a list, or JSON text such as a compute result) is sent as the application/json body, and an unresolved reference fails the step before anything is sent. Other text under `json:`, a number or an empty `json:` is refused at write time and by benmore check (for a text body use `body:`), as is `json:` next to a text `body:`. A text `body:` that is one reference to an object or list sends it as JSON.
