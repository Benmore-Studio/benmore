A step's `retry: N` (a step-level key, beside `run:`) is the TOTAL number of attempts, not extra retries: `retry: 3` runs the step at most 3 times; omitted, 0 or 1 run it once, and a negative value is refused when the file is written (a step that already has one runs once). Between attempts the flow waits `retry_delay`: a Go duration such as 500ms or 5s, or a whole number of seconds such as 5, greater than zero (default 2s, and the HTTP request waits with it). Any other `retry_delay` is refused when the file is written, and a step that already has one waits the default. Attempts stop at the first success, after a transaction rollback, or once an error handler has answered the request. `retry` on an `if:` block, a `for_each:` loop or `run: parallel` is refused at write time, and command flows refuse it. Retry only a step whose effect is safe to repeat.
