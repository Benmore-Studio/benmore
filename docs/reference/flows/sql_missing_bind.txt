A `:name` in a run: sql query binds the request field (body, query string), path parameter or with.params value of that name. When none of them supplies it, the step fails before the statement runs, with `sql: :title is not set: the request sent no field of that name and the step's with.params does not define it` (every missing name, in query order) and the reason `a :name the statement binds had no value; the request did not send it`. A field sent as "" or null is set (binds '' or NULL). A `:name` inside a quoted string or a comment is not a parameter. Give an optional field a value with `with.params` (`params: {title: "${{ params.title || 'Untitled' }}"}`) or an `on.request.inputs:` default; `required: true` refuses its absence with 422 before any step.
