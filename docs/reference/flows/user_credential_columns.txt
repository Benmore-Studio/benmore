A flow SQL step (`run: sql` or `sql_dynamic`) whose query reads _benmore_users never returns the framework credential columns (password_hash, totp_secret, backup_codes, mfa_* and the other names auth responses hide), so `SELECT * FROM _benmore_users` answers without them. The query may still use them (`CASE WHEN totp_secret != '' THEN 1 END AS mfa`), and a column selected under another name is returned as written. A `sql_dynamic` query that interpolates `params.X` (request input) is refused at write time, and at run time on every request. `/static` does not serve TypeScript/JSX source or a `run: compute` module (source or compiled `.js`): compute modules are server code.
