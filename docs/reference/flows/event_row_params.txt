A data-event flow (`on: event: {table, op}`) binds the triggering row's columns as `:name` in SQL as well as `${{ name }}` in templates, like a request body's fields. A `${{ }}` reference inside a larger quoted SQL string (`'n=${{ x }}'`) is refused at write time and by benmore check: it binds as a parameter, which SQLite does not read inside a string; concatenate (`'n=' || :n`) or make the whole string one reference (`'${{ x }}'`).
