Pool queries (auto-CRUD list/read/count, /api/_query, template <query>, gotmpl queries:) carry a 10s default deadline; a statement over it fails instead of holding a connection, at whichever step it is. `BENMORE_QUERY_TIMEOUT` (Go duration; `0` disables) overrides it per app. Statements inside a transaction are exempt, because interrupting one rolls the whole transaction back. List and count paths are also cancelled when the client disconnects.
