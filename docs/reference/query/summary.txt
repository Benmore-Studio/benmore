Declarative cross-cut READ layer. POST /api/_query takes a JSON spec and returns rows. Every identifier is validated against the table's real columns (no SQL-injection surface) and the SAME owner/group/ACL scoping as auto-CRUD is applied - a query can never read rows the caller couldn't read via GET /api/<table>. Single-table (filtered views + grouped reports + pivots); cross-table joins are deferred (they need per-joined-table scoping). Powers QueryView/Report/PivotTable/SavedViews - see api({at:'components'}).
