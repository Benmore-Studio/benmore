An aggregate names its column with `col`: {fn:'sum', col:'budget'}. sum/avg/min/max written with `field:` instead, or with no column, answer 400 saying the aggregate needs "col" (for `field:`, the corrected spec). {fn:'count'} without col is COUNT(*). A `field:` key on count answers 400 too (see unknown_aggregate_keys). Count a column's non-NULL values with {fn:'count', col:'status'}.
