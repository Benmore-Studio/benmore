MCP `sql` with write:true (CLI `benmore sql <app> '<SQL>' --write --confirm`; editor or higher) runs exactly ONE INSERT, UPDATE, DELETE or REPLACE statement, optionally led by `WITH ...`. The statement is tokenized with the shared SQLite lexer, so a leading comment can't hide anything: schema changes (CREATE/ALTER/DROP, triggers, views), PRAGMA (including writable_schema), VACUUM, ATTACH/DETACH, load_extension and a second `;`-chained statement are refused. Make schema changes in schema.prisma; run several writes as several calls, or as one flow with `transaction: true`.
