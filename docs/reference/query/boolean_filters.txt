A where value on a Boolean column binds as the stored 1/0 when it is a JSON boolean, the string true/false (any case) or 1/0, or the number 1/0, with eq, ne, gt, gte, lt, lte and in (`{published: 'true'}`, `{published: {in: ['false']}}`). Any other value on a Prisma `Boolean` answers 400 (`where published: published is a Boolean column, use true/false or 1/0`); on a BOOLEAN column of a schema.sql app it binds as written. Report `sources:` where values follow the same rule. Auto-CRUD list filters: api({at:'scoping'}) boolean_filters.
