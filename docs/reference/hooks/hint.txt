Session context in hooks: {{user_email}}, {{user_id}}, {{user_role}}, {{user_roles}}, {{user_group_id}}. For a signed-in caller these come from the session and override any same-named request field; {{user_group_id}} is the caller's current tenant (an admin's act-as tenant) and is absent when the caller has none. on_update hooks see {{old_<col>}} for change deltas; before_update hooks do not, so an old_* value there came from the request - read the stored row in the hook SQL instead.
