A hook `body:` or `ws:` `payload:` written as a JSON document (it starts with `{`, `[` or `"` and is valid JSON with each `{{...}}` taken as a value) gets its row values written as JSON. Inside a string literal a value is escaped, so a quote, backslash or newline stays part of that string; in a value position (`"tags": {{tags}}`) a value that is already exactly one JSON value (a number, true/false, JSON text such as a json_group_array() result) is written as is, NULL as null and anything else as a JSON string. A row value can never add or override keys of the body or of the message room members receive. Any other template (plain text, a lone `{{col}}`, a fragment that splices several keys from one value) is substituted verbatim.
