A hook `email:` body (inline `body:` or emails/<template>.html) is sent as HTML, so each `{{col}}` row value is escaped for where it lands: text and attribute values are entity-escaped (`<`, `&`, quotes), and a value in href/src loses a script-capable scheme. A row value cannot add links, images or markup to the mail. To send markup stored in a column on purpose, ask for it: `{{{col}}}` is HTML with scripts and event handlers removed, `{{{{col}}}}` is the value exactly as stored (only for content your app wrote). `{{env.X}}` is your own configuration and is not escaped, and a body that is exactly one `{{col}}` is that value as it is (the column holds the whole document your app wrote); `to:` and `subject:` are plain text (CR/LF stripped). An attachment filename's quotes cannot add MIME parameters.
