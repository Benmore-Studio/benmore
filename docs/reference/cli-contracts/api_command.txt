`benmore api <app> [<at> | --at <at>] [--full] [--search "<words>"] [--call '<json>'] [--env dev|prod]` is the CLI form of the `api` tool. `<at>` is `'*'` (the app's routes, the default), `table:<name>`, `'METHOD /path'`, a topic, `<topic>.<key>` or `index` (every topic, one line each); the reference's `api(at:"flows")` is `benmore api <app> flows`. A topic over 8 KiB answers with an index of its keys: read one with `<topic>.<key>`, or add `--full` for the whole topic whatever its size. `--search "<words>"` answers up to 10 `hits` (`at`, `about`, `bytes`), best match first, across all topics or inside the topic given as `<at>`; read a hit with `benmore api <app> <at>`. `--call '<json>'` takes a JSON object and executes the selected route instead of describing it. Flags may be written before or after `<app>` and `<at>`. A second selector, a flag given twice, an empty `--search` and malformed `--call` JSON are usage errors (exit 2) and send nothing.
