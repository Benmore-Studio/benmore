Hosted CLI argument, app-resolution, URL, and exit-code contracts. These are scriptable interfaces: usage errors exit 2 for an unknown or malformed flag on every command (sync-status: 3) and for the argument checks of api, create-app, check, describe, sql, restore, delete-file, verify, ship, qa, skill and login/signup/bootstrap; a missing positional argument on probe, pull, tail, decode, git, feedback, media, dns, github, collaborators, upload and several others prints usage and exits 1. Authentication/authorization exits 4, missing or inaccessible apps exit 5, and transport/server failures exit 1.
