Authenticated auto-CRUD creates with X-Idempotency-Key are deduped atomically with the insert. Identical retries return the original response; changed input/authorization returns 409. Applies to JSON/form creates and `POST /api/<table>/batch`, whose retry with the same key and body answers the first `{ids, count}` without inserting again; not multipart uploads or arbitrary flows. A multipart create that sends the header is refused with 400 (`idempotency requires a key of at most 256 bytes and a non-multipart body`), so leave the header off multipart requests.
