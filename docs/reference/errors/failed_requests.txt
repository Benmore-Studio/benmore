The shared bm request helper reports same-origin 5xx responses and network failures, with method, path and status; 4xx responses add a breadcrumb only. Network failures still reject the original call. Requests to /api/_errors never report themselves. Unhandled API rejections preserve status and a validated 8–32 lowercase hex request_id; failed requests also accept X-Request-Id. Search request_id:<id> in Sentry to correlate the browser failure with server diagnostics and request logs.
