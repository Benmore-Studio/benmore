bm.captureError(error, {tags}), bm.captureMessage(message, 'error'|'warning'|'fatal') and bm.setTag(key, value) work in the embedded SDK and @benmore/bm; without fetch, capture is a no-op. Up to 10 tags have lowercase [a-z0-9_.] keys (1–32 characters) and string values of at most 200 characters. Every payload includes the last 30 navigation, request, console.warn/error and click breadcrumbs; fields cap at 300 characters. Clicks carry data-testid or tagName#id only, never text, values or classes. URL queries/fragments are removed; server validation and export scrubbing apply again. A rolling ten-minute window allows 25 reports, deduplicated by severity, message and top frame.
