A bounded queue (256) per app captures server/HTTP 5xx failures, request and worker panics, terminal job failures, cron failures, asynchronous hook warnings and TSX compile failures. Kinds include server, http5xx, worker, job, cron, hook and compile. 503/507 capacity responses and 4xx before-hook refusals are excluded. Panic frames are captured while unwinding. request_id links the group, request log and the existing response header/JSON body; a raw 5xx gets a local correlation id without modifying an already-written response.
