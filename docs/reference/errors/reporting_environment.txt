SENTRY_ENVIRONMENT and SENTRY_RELEASE override the default environment (dev for a -dev instance, otherwise production) and release (<logical app>@<BENMORE_PUBLISHED_AT>, otherwise benmore@<version>). An optional browser release is ignored; the app controls release identity. These three settings (SENTRY_ENVIRONMENT, SENTRY_RELEASE, BENMORE_PUBLISHED_AT) are configuration, not secrets: the scrubber never replaces their values, so a configured release matches the release CI uploads source maps to. If the scrubber still changes a trusted app, environment or release identity (another env value inside it, such as an app name of 8 or more characters in the default release), its exported value becomes a stable kind-prefixed opaque digest instead of a shared redaction placeholder. This keeps production apps and successive deployments distinct without revealing masked values; affected identities are not human-readable. Generic text/tag/breadcrumb scrubbing applies as in export_privacy.
