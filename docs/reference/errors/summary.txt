An /api/ error answers the JSON envelope { error: 'short_code' or text, message?, hint?, request_id?, docs? }; some routes add keys of their own (stripped_fields, locked_by, failed_step). `docs` is the address of the reference key that states the refused rule (docs_field). Status codes follow HTTP conventions. Branch on the status first and parse the body as JSON only when its Content-Type is application/json, as `bm` does: a body that is not this envelope (a proxy's error page, a route that has not adopted it) is text or HTML, and an unconditional res.json() throws on it. Auto-CRUD refusals (a missing row, CSRF, a missing id), flow input refusals (422), flow gate refusals (401/403/429) and failed flows all answer this JSON envelope.
