Set the app's SENTRY_DSN to https://<public_key>@<host>[/<prefix>]/<numeric_project>. HTTPS only; no password, query or fragment; private or unresolvable hosts are refused at delivery and actual dial addresses are guarded. Events use Sentry envelopes, random event ids and oldest-first stack frames. The per-app external forwarding cap is 30/minute for server events and a separate 30/minute for browser reports; each monitored cron job has its own check-in budget. 401/403 rejects the DSN for 10 minutes; 429 respects category-specific X-Sentry-Rate-Limits or Retry-After (60 seconds by default).
