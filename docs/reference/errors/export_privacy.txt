Exported text masks complete credentials and app environment values of at least 8 characters before normalization or field truncation, then applies email and 9-or-more digit masking. Oversized fields are omitted whole. Breadcrumb timestamps must parse as RFC3339; invalid text is omitted. Context lines come only from cached inline sourcesContent, never from source-file reads during reporting. The only default user field is user.id; SENTRY_SEND_PII=1 permits session user.email. Client IP, cookies, request bodies, URL queries/fragments and headers other than User-Agent are not collected for export. Local client diagnostics, including stack_raw, remain available. Viewer group reads additionally mask email/IP-shaped text recursively.
