@relation supports fields/references and an optional quoted relation name. onDelete and onUpdate arguments are not applied: the compiler emits a bare foreign key, with no cascade, set-null or explicit action clause. The write gate and `benmore check` refuse these arguments on both forward fields and reverse model lists; quoted relation names containing these words remain accepted. Remove unsupported action arguments and handle related rows explicitly, for example delete children before their parent through native CRUD or a native transaction. Existing schemas keep loading with their prior foreign-key behavior; this authoring check does not install cascades or migrate existing constraints.
