Adding a column whose default is not a constant - `DateTime @default(now())`, `@updatedAt`, or a required `DateTime` with no default (backfilled with the migration time) - to a table that holds rows works. SQLite refuses such a default in ALTER TABLE ADD COLUMN on a non-empty table. Benmore adds the column by a preserving table rebuild (rows, rowids, indexes and triggers kept; existing rows get the migration time, later inserts the default) and journals the rebuild in the migration file so the other instance replays it. An empty table still gets a plain ALTER. A table that another table references by foreign key is not rebuilt: the migration fails with a message to make the field optional, give it a constant default, or add it in an explicit migration.
