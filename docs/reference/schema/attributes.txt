Field attributes the compiler applies: @id, @unique, @default(...), @map("..."), @relation(fields: [...], references: [...]), @updatedAt. Block attributes: @@id([a, b]), @@index([a, b]), @@unique([a, b]), @@fulltext([a, b]), @@map("table"). @db.*, @ignore, @@ignore and @@schema(...) are accepted and do nothing. Any other attribute - a typo like @uniqe, @unique(map: ...) / @id(...) with arguments, or the named form @@unique(fields: [a, b]) - is refused by the write gate and `benmore check`, because the compiler skips it and the column would get no constraint.
