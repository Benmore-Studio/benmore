The write gate (write_file, edit_file, `benmore push`, `benmore deploy`) and `benmore check` read retention.yaml, computed.yaml and app.yaml `aggregates:` the way the app does, and refuse what would not run as written. Each feature's topic lists its rules: api({at:'retention'}) keys, api({at:'aggregates'}) declare, api({at:'computed'}) declare. An app that was deployed with such a file keeps loading; the policy, aggregate or field it concerns does not run and the app's log says so at every start. A push of another file reports a refused retention.yaml the app already has as a warning.
