Generic CRUD single/batch/transaction writes and NDJSON ingest validate the scalar types in the successfully loaded schema.prisma before lossy conversion. Integer fields require an exact signed 64-bit integer, Float fields finite numbers, Boolean fields true/false or 1/0, String fields strings, and DateTime fields valid calendar dates or date-times. Numeric form strings remain accepted; nullable empty HTML numeric/date controls clear to null on updates; single creates omit blank optional controls and retain defaults. JSON empty strings are values, not null. Explicit null is rejected for required fields even when a default exists; omission retains defaults and missing required fields are refused. Mixed invalid batches roll back; ingest skips invalid rows and reports durable counts. SQL-only schemas retain SQLite affinity semantics. Existing invalid rows are not rewritten, and app-authored SQL is not covered by this input gate. Pending source edits do not change the accepted loaded schema.
