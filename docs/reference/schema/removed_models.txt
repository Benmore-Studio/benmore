A schema.prisma write (write_file, edit_file, `benmore push`, `benmore deploy`) that removes a model whose table still holds rows is refused, naming the table and its row count; the app would drop that table when it reloads. Keep the model to keep the data, or write again with allow_table_drop (`benmore push schema.prisma --allow-table-drop`) to drop it - a backup is taken before the drop and `benmore restore` lists it. Empty tables and instances without data are not checked. Promote applies the same rule to prod (force).
