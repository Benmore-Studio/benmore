schema.sql is read with a full SQLite scanner: one-line and multiline declarations, quoted names, nested commas, table-level primary keys and raw executable defaults are understood. Constraint words inside literals and foreign-key SET DEFAULT actions do not replace column constraints/defaults. Adjacent CHECK(...)NOT NULL preserves nullability during migration. Column names are matched case-insensitively (ASCII), as SQLite does, including the tenant key column. For a reviewed MCP connector, TSX and private compute are compiled from the reviewed app sources in a separate process with a five-second bound and an eight-MiB output limit. The connector does not support relationship includes; such a request is refused.
