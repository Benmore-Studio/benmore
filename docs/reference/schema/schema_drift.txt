Schema drift (`benmore check`, the app-load log) compares schema.prisma with the live database. Columns the framework adds to an app table are not drift: a blind-index sibling `<col>_blind` beside its encrypted `<col>` (encrypted.yaml blind_index) and a custom field added through POST /api/_schema/{table}/fields. Never drop them - `<col>_blind` is what equality search on the encrypted column reads. The app-load log lists each issue (`[extra_column] notes.stray`, at most 20) after `schema drift: N issue(s)`. `benmore check` explains each issue.
