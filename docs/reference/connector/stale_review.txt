When mcp.yaml or a file the app loads or serves changes after the review, the app keeps starting and serving and only its connector is off until the source is reviewed again. `benmore serve`'s start-up check, `benmore check` (check_app), the check after a write and `benmore test` report this as one warning on mcp.yaml with source `mcp_review`; it is not an error, and it fails no push, check or test run. After reviewing the source changes run `benmore mcp review <appdir> --reviewed` and `benmore mcp check <appdir>`, then push the reviewed files together (a hosted app) or reload or restart the service (a self-hosted one); if the app serves no connector, delete mcp.yaml instead. Rewriting mcp.yaml by hand does not clear it. A write of an mcp.yaml whose digests do not match the source is still refused. How a review binds the source and what the digest covers: `connector_source_review`.
