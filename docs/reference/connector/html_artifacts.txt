HTML artifacts work on hosted apps: the bytes are stored as `<id>.html.bin`, which the platform media store types application/octet-stream with an attachment disposition (HTML is never served from the shared media domain). They are read only by GET /api/_mcp/artifacts/{id}, which rechecks owner, tenant, role and scopes and downloads the report as text/html. `artifact.export` separates a refusal (denied: unknown, foreign or uncommitted receipt, lost scope) from a failure after authorization (formatting or storage: incomplete_result, renderer: unavailable_provider, both logged), as artifact.create does.
