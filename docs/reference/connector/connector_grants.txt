The app-facing MCP connector is the endpoint /api/_mcp on the app's own host: it lets the app's users reach reviewed tools from an AI assistant. It is distinct from the platform /mcp used to build and manage apps. Nothing is exposed until a reviewed mcp.yaml is loaded, the app owner has switched the connector on for that instance, and a user has connected a client and consented to explicit scopes. The offline authoring guide is `benmore docs connector`. This topic is split by subject; read the key that matches the question. Authoring and deploying: `new_app_workflow`, `manifest_authoring`, `connector_source_review` (digests, `benmore mcp review|check|inspect|generate`, `benmore serve --mcp-local`), `stale_review` (a check warns that the connector is off after a source change), `review_serialization`, `destructive_schema`. Connecting: `connector_oauth` (origin, consent pages, tokens, a user's connected clients, transport), `hosted_test_recipe`. Tools and reads: `connector_tools` (tool kinds and schemas), `connector_reads` (the read envelope and row revisions). Approved writes: `connector_commands` (declaring a command: shape, permissions, prepare and its refusals, session revocation), `connector_command_sql` (what command SQL may bind and call: actor and parameter bindings, SQL functions, tables, generated values, triggers), `dependency_shape`, `caller_predicate` (the review warning for a command whose SQL binds nothing from the actor), `command_encryption_key`, `connector_approval` (review page, batch approval, auto-approve, review text), `review_page_state`, `connector_commit` (_commit, _status, attempts, retries, limits), `connector_hooks_effects` (hooks, queued deliveries, effect status), `command_hook_context`, `connector_owned_fields` (`command.owns`). Files and output: `connector_files`, `connector_artifacts`, `html_artifacts`, `connector_resources` (MCP Apps components). External systems: `connector_external` (connections, per-user credentials, transfers). Operating: `connector_owner_switches` (enable, disable, revoke, enrollment, restarts), `revision_trigger_order`, `diagnostics`, `connector_errors` (the stable error codes), `connector_lifecycle` (password change, account deletion, restore, key rotation), `connector_telemetry`. Limits are stated in the section they apply to.
