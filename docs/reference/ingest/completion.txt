A fully read stream with accepted rows returns 200 with status completed, ingested (committed rows) and errors (skipped invalid rows); an empty stream or one with no accepted rows returns 400. An interrupted read returns 400, or 413 for the 100 MB body / 1 MiB line limit, with an error, status partial if a valid prefix committed or failed if none committed, and a terminal read error included in errors; a partial error names the committed rows ("... the 42489 rows accepted before line 42490 were committed"). The row limit is 100000: exceeding it rolls back the request and reports ingested:0. Do not replay a partial import blindly; reconcile its committed prefix or use the resumable import API for all-or-nothing loads.
