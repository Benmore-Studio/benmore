`benmore test` first runs the source checks a push runs (the write gate's per-file validators and the cross-file checks; the database is not opened) and reports each error as a failed result, `source check (<validator>)` with the file and the gate's message, before the tests (which still run). A flow under a reserved prefix such as `/api/v1/` is such an error, as it is for `benmore push`; name app routes under `/api/<your-name>/` without a leading `_`. Warnings are not failures. The first line of the text output (`test: 4/11 passed`) and the `SUMMARY` entry of `--json` (`4/11 tests passed`) count every result of the run, these source checks included.
