A verify report names the instance it checked (`environment`: always dev), marks a check the profile includes but that did not run as `not_run` with a `reason` (YAML tests and journeys after a failed acceptance contract, no journeys, --quick without smoke journeys), and lists `next_steps`: per failed check the command or evidence file to read next (sync → `benmore sync-status <dir> --env dev --json`, yaml_tests → tests.json, journeys → journey-*.json or `benmore qa draft`, release_safety → `benmore status`/`benmore doctor`). `ok` is true when `failures` is empty; text output prints the same as `NOT RUN:` and `Next:` lines.
