A YAML test step with `files:` sends a multipart/form-data body, as a browser form with a file input does: each entry maps a form field name to `{name: <file name>, content: <text>}`, and the step's `data:` fields and the CSRF token travel in the same body. `files: {}` sends a multipart body with fields only. Example, a create on a table with a file column: `- api: "POST /api/notes"` / `data: {title: scan}` / `files: {attachment: {name: scan.txt, content: hello}}` / `save: {file_path: attachment}`, then `- get: "{{file_path}}"` to read the stored file back. `{{var}}` is replaced in the file name and content.
