Sending email from an app. On the hosted platform every app sends OUT OF THE BOX - zero configuration: flow/hook `run: email` steps and framework auth emails (OTP, verification, password reset) deliver via the platform email service (Amazon SES under the hood) from the app's default address `<app-sub>@mail.benmore.ai`, with the app's display name as the sender name. To send from the user's OWN domain instead, verify it once (dashboard → app → Email, `benmore email-domain <app> add <domain>`, or the `email_domains` MCP tool) then set EMAIL_FROM. The platform SES service is the ONLY sender on the hosted platform - per-app provider env vars (SMTP_*) apply off-platform only.
