Authenticate the hosted Benmore CLI. `benmore login` signs in through the browser (the dashboard sign-in, including its emailed code); headless runs use `benmore login --device`, or a token from an earlier browser login via `--token-stdin` or BENMORE_TOKEN (`--token TOKEN` still works but prints a warning: it shows the token to `ps` and shell history). Credential precedence is explicit flags, then BENMORE_* environment variables, then the browser flow.
