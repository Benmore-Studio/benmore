Run `benmore login` once in a browser; the platform mints the CLI token and stores it mode 0600 at ~/Benmore/.config/credentials (or $BENMORE_HOME/credentials). Treat its `token` field as a secret when copying it into a CI secret store. The browser's one-click "Continue as <you>" (/auth/cli-session) mints only from your own full dashboard sign-in: an API token, a scoped session, support impersonation or act-as gets 403. Minting a new CLI token replaces the previous one, and a password change or reset rotates it, so update the CI secret afterwards. The browser hands the token to the CLI's loopback listener as a POSTed form, never in a URL, so it does not stay in browser history (an outdated CLI receives it in the callback URL, so keep the CLI updated).
