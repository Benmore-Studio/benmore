`login`/`bootstrap --email EMAIL --password-stdin` (or `--password PASSWORD`, which warns), BENMORE_EMAIL + BENMORE_PASSWORD and `benmore signup` call POST /platform/login and /platform/signup. A platform whose dashboard requires the emailed sign-in code (its `auth.otp` setting; benmore.ai does) answers both with 403 before checking the password, and the CLI exits 4. Create the account and sign in through the browser instead. The password path works only on a self-hosted platform that does not require the code.
