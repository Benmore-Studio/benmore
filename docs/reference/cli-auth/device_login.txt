`benmore login --device` is the headless path for any account, including Google-only ones: the CLI prints benmore.ai/auth/device and an XXXX-XXXX code, then polls; the person opens the page on any device where they are signed in to Benmore (a direct sign-in, not an API token, scoped session or impersonation), TYPES the code (a link never fills it in, so a URL someone sends cannot carry their code), sees the network address and time the code was requested from, and approves. Codes expire after 10 minutes and redeem once; the token is minted on redemption, rotating the account's CLI token as a browser login does. A password change or reset on the account cancels an approval that has not been redeemed yet (the CLI then gets access_denied). Only approve a code from your own terminal. Endpoints: POST /auth/device/code, POST /auth/device/token (RFC 8628 errors: authorization_pending, slow_down, access_denied, expired_token).
