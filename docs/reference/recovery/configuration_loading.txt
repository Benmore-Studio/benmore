Startup and reload reject malformed app.yaml, hooks.yaml, flows.yaml/flows/*.yaml, workflows.yaml, cron.yaml, encrypted.yaml, env.yaml, and the generated environment file before the database is opened or migrated. app.yaml checks include backup duration/retention and the shapes of auth, roles, access, groups, scopes, and encryption settings. Missing optional files deliberately remove their configuration; unreadable files are errors. Backups require interval >= 1m and a positive integer keep (default 20). Legacy root flow maps load alongside GHA flow files, but new writes require the GHA form. Cron accepts a jobs list or named-job map, with flow or inline run/steps; invalid or partially parsed jobs fail the load. Fix the named file and retry the push/reload. This does not roll back schema changes already committed by an earlier operation. The write gate and `benmore check` also refuse an app.yaml key nothing reads: an unknown top-level key, and an unknown key under auth:, csp:, groups: or features:. The refusal lists the keys that exist.
