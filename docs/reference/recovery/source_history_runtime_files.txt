Automatic source history and GitHub export checks protect every data.db* runtime file, including SQLite rollback/super-journals and database backups. Mandatory ignore rules cover the database and its SQLite sidecar files without excluding ordinary source directories or overriding custom ignore rules. A history that already tracks such a file blocks the affected history, restore and export operations until a platform operator removes that path from the instance's history (see api(at:"github.history_safety")). That removal leaves the runtime file itself in the app directory, byte for byte: env.yaml, the database and uploads stay where the app reads them, and only the history and the index lose the path. Nothing erases committed bytes or rewrites history automatically.
