PITR covers an instance only from its first successful base upload. A failed base is retried, with a 1-second to 1-minute delay. PITR covers production instances only, needs backup storage on the platform, and is on for an app whose production environment sets `BENMORE_WAL_SHIP=1` (`benmore env <app> set BENMORE_WAL_SHIP=1 --env prod`). Once it is turned on, shipping starts within ten minutes. `benmore restore <app> --pitr --as-of <time>` on an instance nothing was ever shipped for (a dev instance, or a production instance without PITR) answers that point-in-time recovery is not enabled for this instance and what turns it on; `no PITR snapshot at or before <time>` means PITR is on and the time is before its first base upload.
