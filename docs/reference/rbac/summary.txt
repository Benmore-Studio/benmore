Multi-role RBAC. A user holds ANY number of roles via the _benmore_user_roles join table; the effective scope set on a session is the UNION across every held role plus their inherited parents. Two access modes layer on top: role:a,b,c (any-of) and perm:<resource>.<action> (granular). Tenant-scoped grants: a grant is either GLOBAL or scoped to a specific group_id, so the same user can be admin in tenant A and viewer in tenant B with zero cross-tenant leakage. The legacy _benmore_users.role column is still the PRIMARY role (drives the `admin` mode shortcut, exposed as {{user_role}}); multi-role layers on top. Which key answers which who-may-see-this-row question: api({at:'access.which_topic'}).
