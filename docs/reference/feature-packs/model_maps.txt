Exact model maps are simultaneous. HandoffItem=Handoff and Handoff=Task install distinct Handoff and Task models; a mapped destination is never fed through another model/table mapping. Swaps are supported when final names remain distinct. References inside every pack model follow the mapping, including relations in models whose own names stay unchanged; inferred table references in SQL and native CRUD callers follow the same one-pass rule. Names are replaced only as whole words, and a known route literal is not rewritten by a model map. Duplicate final model names, collisions with the target app and unsafe explicit table mappings are refused before apply; an install does not rename or migrate existing target data.
