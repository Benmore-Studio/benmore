Route and model transforms compose independently for exact known route literals. With --route-prefix ops --model-prefix Ops, a declared custom /api/handoffs/:id/complete becomes /api/ops/handoffs/:id/complete, while SQL table references and native CRUD /api/handoffs become ops_handoffs and /api/ops_handoffs. Model-only transforms preserve declared custom routes. Exact route-map targets are emitted once, without further model or route rewrites. Only complete known route literals are transformed: arbitrary JavaScript concatenation, interpolated URL construction and concrete IDs substituted into a :parameter pattern are not inferred. Inspect these call sites in the preview and adapt them explicitly before using the installed module.
