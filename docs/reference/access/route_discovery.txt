Route discovery reflects `off`. api(at:'*') (and `benmore api <app> '*'`) lists in crud_routes only the auto-CRUD routes some caller can reach; a route whose access op is `off` moves to crud_access_off, since it answers 404 to everyone, admins included (a table with every op off keeps an empty list). api(at:'table:<t>') moves such routes to access_off_routes, a route describe carries access_off: true, and the generated OpenAPI and /api/_docs leave the operations out (restore needs read and update; a table whose every op is off is left out).
