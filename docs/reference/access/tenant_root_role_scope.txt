On groups.bootstrap.org_table without the groups key column, role: and perm: policies scope tenant-held authority by id = the effective tenant, even when bootstrap stored the founder in user_id. Non-founders with the declared role can read/update their own tenant; owning a different tenant never substitutes for the current tenant role. Matching primary/global roles retain global access, while admin act-as remains inside the acted-as tenant. Explicit self and owner_or_role policies retain their declared owner semantics.
