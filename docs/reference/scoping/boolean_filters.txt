A list filter on a Boolean column (declared BOOLEAN, which reads return as true/false and bm.d.ts types `boolean`) takes true/false (any case) or 1/0 and matches the stored 1/0: `?published=true`, `?where[published]=false`, `?published__ne=true`, `?published__in=true,false`, the range operators, `?count=true`, `?page=` totals, `?cursor=` pages and `bm.table(t).list({where: {published: true}})` / `count(...)` alike. On a Prisma `Boolean` any other value (`?published=maybe`, an empty value) answers 400 `<table>.<col> is a Boolean column: filter it with true/false or 1/0`; a BOOLEAN column of a schema.sql app still matches other text as written, since its writes store any text. `__like` compares the stored 1/0. POST /api/_query does the same (api({at:'query'}) boolean_filters). A row whose Boolean holds the text 'true' (written by raw SQL) reads true but matches neither filter; store 1/0.
