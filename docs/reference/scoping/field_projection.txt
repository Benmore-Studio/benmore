?fields=a,b on a list (GET /api/<table>) and on a single-row read (GET /api/<table>/<id>) returns only those columns, resolved the same way on both: a name that is no column of the table, or a hidden column (see hidden_columns), is dropped without a header; when nothing is left the full row comes back; encrypted columns are masked per row exactly as without a projection. A point-in-time read (?as_of=) and a version snapshot (GET /api/<table>/<id>/versions/<v>) apply the same projection to the source table's columns, after masking. The history columns (_version, _valid_from, ...) come back only without a projection.
