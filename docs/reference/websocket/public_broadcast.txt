By default both /ws AND /sse/events require a session when the app has auth configured. Set `features.ws_anonymous: true` in app.yaml to open them up - useful for public chat rooms, demos, broadcast dashboards. Same-origin + connection-cap checks still apply. Feature switches read no/off as false; ws_anonymous is enabled only by true/yes/on. A bare number is refused at write time (`features.ws_anonymous must be true or false, got 1.`); only the quoted strings "1"/"0" are read as on/off.
