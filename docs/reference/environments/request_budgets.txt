Hosted request budgets are per app, not per account. The hosted platform charges each non-static request to the app that answers it - an app's dev instance (<sub>-dev) and prod instance are separate apps, and a verified custom domain counts as its app - at 600/min per client IP, plus an overall 1200/min per IP across every host; the platform API (/platform/*, /mcp, /oauth/*, which the CLI uses) has its own 300/min per IP. Traffic to one app therefore never spends another app's budget or the CLI's. Each app also applies its own 300/min per IP (RATE_LIMIT_PER_MIN env var; 0 disables), and declarative `rate_limit:` on a flow applies on top. Every 429 from these limiters carries Retry-After in seconds and is sent before any handler or flow step runs, so the request had no effect; the CLI waits and retries such a 429 up to 3 attempts when the wait is 30s or less. Static assets (/static/, /_internal/, /uploads/, common asset extensions) never count.
