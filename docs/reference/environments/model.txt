One logical app = two instances: dev (<sub>-dev, where you build) + prod (<sub>, what you publish), each with its OWN data.db - promote never moves data. The platform_apps row + ownership + billing + custom domain are keyed on the logical (prod) subdomain. An existing prod app gets a dev instance with `benmore seed-dev <app>` (copies prod code, fresh empty dev data; prod stays untouched, incl. its custom domain).
