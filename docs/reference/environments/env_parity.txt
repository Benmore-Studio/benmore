Promote (and its dry run) and doctor warn about env vars the app's runtime config requires but prod lacks (shared or prod scope): `env_warnings` lists the keys and `env_warning_files` the files that read each. Only files the runtime loads are read (top-level *.yaml except env.yaml, flows/*.yaml), comments are ignored, and a read that cannot fail is not listed: an `if:` condition (a missing value is false) or a `{{ }}` with a `| default:` or `||` fallback. Any other `${{ env.X }}` fails the step that renders it when it runs (an HTTP flow answers 500 template_unresolved). Platform-reserved names are never listed.
