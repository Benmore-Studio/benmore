Uploads on the platform media CDN are per instance too: prod stores under `<sub>`, the dev instance under `<sub>-dev`. A dev instance's uploads and delete_upload touch only `<sub>-dev`; it can still serve (read) production's files, so data copied by `refresh-dev --with-data` and older dev uploads stored under `<sub>` keep displaying. promote copies no uploads. See api(at:"uploads") `storage_backends` (the `dev_instance_prefix` item).
