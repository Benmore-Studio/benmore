A version's _changed_by is the user id of the signed-in caller whose write replaced that state: an API update (single, batch, /api/_transaction, revert, restore), a delete, or a workflow transition. It is the same id the audit log records as user_id (the impersonated user during support impersonation). Writes with no caller leave it null: flow, hook and cron SQL, migrations, the SQL console, and workflow timeouts. Versions recorded by an older runtime keep a null _changed_by.
