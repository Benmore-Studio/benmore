Enable history in app.yaml with versioned: [documents] or a YAML block list of table names. Quoted names and inline comments follow YAML syntax. Omitted, null and [] disable history. Other shapes, invalid identifiers and duplicate table names are rejected before startup/reload changes the database. A name that is not a table of the app (a schema model or a table a migration creates) is refused at push and by benmore check, and so is a framework table (api({at:'schema'}) framework_tables).
