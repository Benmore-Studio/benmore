History follows the row id, but each snapshot is served only to callers who could have read it: the row scope (owner, tenant, membership, record grant) is evaluated on the SNAPSHOT's own user_id / group key, not the current row's. After an ownership transfer or tenant move, the new owner sees only versions from their own tenure - earlier versions are omitted from /versions and answer 404 on /versions/{v}, /revert/{v} and ?as_of=. Record-level grants on the row also reveal its snapshots. Admins (not stepped in) see the full history. A broad read rule does not open history: under `read: everyone` (or `anon`) every signed-in user lists and reads the current rows, but /versions, /versions/{v}, /revert/{v} and ?as_of= still answer 404 to a caller outside the row scope (not the owner, not in the row's tenant, no record grant). Earlier values may have been removed from a row on purpose, so they stay with the people the row belongs to; publish a past value by writing it to a column of the current row.
