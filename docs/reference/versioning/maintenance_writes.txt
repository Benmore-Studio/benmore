One version per write. A version is the state an UPDATE or DELETE replaced; an insert records none. Framework follow-up writes add no version of their own: a computed.yaml `expr:` field's recalculation (it writes only when the value changes), encryption normalization, blind-index siblings, and the Prisma @updatedAt rewrite after a raw UPDATE that left updated_at alone when the recorded history already reaches the new timestamp. A timestamp-only write past the recorded history (an explicit touch) is still a version, and aggregate `sql:` fields are content (their value follows other tables). Existing history is not rewritten; the triggers are replaced on the next start or reload.
