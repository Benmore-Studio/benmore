GET /api/<table>/<id>?as_of=<timestamp> accepts RFC3339 instants with timezone offsets or SQLite UTC date/time text. For history stored in the framework's standard SQLite UTC format, equivalent instants select the same history interval (valid_from inclusive, valid_to exclusive); invalid timestamps return 400. Query normalization preserves fractional seconds but does not rewrite imported timestamps stored in other formats. History is recorded at the trigger's stored timestamp precision. ?fields=a,b projects the point-in-time row and GET /api/<table>/<id>/versions/<v> the same way as a live read (scoping → field_projection), after masking. A point-in-time read applies no ?include= and lists each entry in X-Ignored-Params.
