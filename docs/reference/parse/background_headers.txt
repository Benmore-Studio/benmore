`source: headers` is refused by the write gate and `benmore check` in an async (`mode: async`), scheduled or data-event flow. Those run in the background with no request, so there are no headers to read, and carrying headers with the job would write credentials (Authorization, Cookie, API keys) into job payloads. Parse the header in an inline flow and `run: enqueue` only the value you need. A file already deployed keeps loading and the app logs the problem.
