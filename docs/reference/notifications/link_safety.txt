`link` is a URL your UI puts in an href, and a hook fills it from row values. A link with a script-capable scheme (javascript:, vbscript:, data: other than a raster image) is never stored: the notification is created without a link. title and body are stored as plain text - escape them when you render (set textContent or use bm.html`...`, which escapes values; in SSR use `{{title}}`, not `{{{title}}}`).
