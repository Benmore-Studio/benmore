Full-text search supports UUID and other text primary keys. FTS stores a separate SQLite integer row identity; returned ids, ordering, tenant/owner scopes and hidden-field exclusions stay unchanged. Startup/reload atomically replace earlier text-id indexes and rebuild from existing records; integer-id indexes keep their existing definition. A text-key SQL table must provide an unshadowed SQLite rowid alias (ordinary Prisma tables do); a text-key WITHOUT ROWID table or a table shadowing all three aliases is refused before creating an index.
