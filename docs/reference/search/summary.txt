Full-text search via SQLite FTS5 (trigram tokenizer) uses `?q=` on the list endpoint (GET /api/<table>?q=...). Requires @@fulltext on the fields to index in schema.prisma; @map column names and @@map table names are resolved to their physical names. Without @@fulltext, q is ignored. Results keep normal list ordering and row scoping; orderBy controls ordering. The table keeps its normal access rules: a model with no `user_id` column and no `access:` rule is admin-only, and `?q=` answers 404 for everyone else.
