Sharing, revocation and permission-listing require the row owner or an admin grant, plus current update policy and edit row authority; a global admin outside act-as bypasses that row authority check. The share and revoke routes require table write scope and cookie CSRF. Listing checks table read scope too, but a non-admin owner's read-only token still fails the shared update-authority check (403); table write scope includes read. A scoped global-admin credential still needs the route's explicit scope. No grant bypasses current tenant restrictions.
