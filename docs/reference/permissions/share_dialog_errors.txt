sdui.ShareDialog shows an escaped load error and Retry when permission listing fails, including 401 after session revocation and 403 without sharing authority (on a table whose record sharing is turned off, a 403 shows the turned-off state instead: see `sharing_switch`). A failed refresh removes stale grant and share controls; it never says Not shared with anyone unless listing actually succeeds with an empty result. Retry and refresh re-run the native permission check and restore the list only on success. Only the latest refresh can publish its result; older pending successes/errors cannot overwrite it, and destroy prevents pending requests or later refresh calls from rebuilding the dialog.
