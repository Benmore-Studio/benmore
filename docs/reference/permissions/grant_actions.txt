Record grants are action-specific: view permits read; edit permits read and update; delete permits read and delete; admin permits all three plus sharing management. Delete does not imply edit, so a delete-only recipient cannot PATCH or restore a soft-deleted row (restore requires read and update). This describes the existing native policy, not an authority expansion. Table policies, credential scopes, tenant/member predicates and encrypted-field masking still apply. Expired and revoked grants contribute no authority.
