On a table with the groups: key, a grant only reaches a grantee whose EFFECTIVE tenant is the row's tenant - the tenant clause is AND'd around owner rows, role tiers and grants alike on every CRUD surface. A share to a user in another tenant is inert (404 for them). In `group` mode every tenant member already reaches every tenant row, so grants add nothing there; they matter for owner-scoped modes (`self`, `owner_or_role`, `member-of`). A signed-in user with NO tenant still reaches rows explicitly shared with them.
