sdui.ShareDialog displays the native permission list grantee_id and revokes that listed grant by id through the existing DELETE /api/<table>/<row>/share/<permissionId> endpoint via bm.api. Revoking by id works for every listed grant, including grants with the same recipient spelling; bm.permissions.revoke takes the recipient's email. Display text and attributes remain escaped; scope, CSRF, tenant and sharing-authority checks stay in the native endpoints. The component uses the same list envelope and empty-grant state as bm.permissions.list.
