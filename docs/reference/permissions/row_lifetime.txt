A grant belongs to the row it was made on. Hard-deleting the row through auto-CRUD (single, batch, /api/_transaction) deletes its grants and any lock in the same transaction, so a new row that reuses a deleted id (a plain INTEGER PRIMARY KEY without AUTOINCREMENT) inherits nothing. A soft-deleted row keeps its id and its grants. A row deleted by a flow, hook or SQL keeps its grant rows - delete from _benmore_permissions there too, or use AUTOINCREMENT / UUID keys (schema.prisma always does).
