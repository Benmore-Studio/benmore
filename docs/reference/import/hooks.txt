Atomic CSV/NDJSON import and owner SQL restore intentionally do not run per-row before-hooks, after-hooks, event flows, webhook subscriptions or audit entries. Database constraints and installed SQL triggers still apply. Successful completion records one import audit entry and sends an aggregate notification (table insert for Mode A, refresh for Mode B). Use ordinary CRUD, /batch or streaming ingest when before-hook validation is required; streaming ingest also omits per-row after-effects. Import remains the privileged, all-or-nothing data-load path, not a substitute for business operations implemented in hooks.
