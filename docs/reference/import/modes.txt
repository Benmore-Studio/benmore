Mode A - `format: "csv"` or `"ndjson"` - loads one `table`. Mode B - `format: "sql"` - runs a multi-statement script (INSERT/UPDATE/DELETE/REPLACE/WITH only) across as many tables as the script names; `table` is ignored. Mode B DML is not table-gated and can reach framework tables such as `_benmore_users` (the authority `sql` write:true already grants), so only run scripts you trust.
