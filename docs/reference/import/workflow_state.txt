A workflow's state column is never importable, so a file cannot place a row in a state: naming it in a CSV header or the declared `columns` is refused, and an NDJSON key of that name is ignored. Mode A writes the workflow's `initial` state into it for every row, like an API create, whatever the column default is. A workflow with no `initial:` still leaves the column to its default. Mode B runs the script's own INSERTs unchanged, so a restore script sets the state itself. See `api(at:"workflows")` (`create_null_state`).
