A committed import's row carries a lease (lease_expires_at, 2 min) covering the moments before its load transaction begins; the open transaction then holds the database write lock, which is the liveness proof. A row whose process died is failed ("interrupted ... lease lapsed") at the next app start or by the next status/commit/cancel call on it, in every mode including BENMORE_CLUSTER=true. A chunk PUT and a commit of the same import are serialized, so a retried chunk cannot delete a part the load is about to read.
