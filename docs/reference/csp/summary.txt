Per-app Content-Security-Policy allowlist extensions. The framework ships a strict default CSP: 'self' (which covers the /_internal/ libraries - Tailwind, HTMX, Alpine, Chart.js, Mermaid, Lucide), Google Fonts, Inter from rsms.me, the Cloudflare analytics beacon when the operator enables it, and a public script CDN only when the app's own source names it (see `script_cdns`). For external map providers, payment iframes, or any other third-party origin, add the host to the right directive under the top-level `csp:` block. Values are appended - they widen the policy, never replace it - except `frame_ancestors: "'none'"`, which denies every frame and replaces the default framing sources.
