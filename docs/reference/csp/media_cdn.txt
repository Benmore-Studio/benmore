With the platform media CDN configured, its one origin is in img-src, media-src and connect-src by default, so page code can `fetch(await bm.signedUrl(...))` or fetch a public upload (hls.js, a CSV preview, a canvas frame) without a csp.connect_src entry. The CDN answers GET/HEAD with Access-Control-Allow-Origin: * and no credentials; the signed URL is the permission. Local-disk uploads are same-origin and need nothing.
