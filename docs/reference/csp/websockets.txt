connect-src does not allow every WebSocket host. The default is `'self'` plus the page's own realtime origin (`wss://<host>` and `ws://<host>` of the request, which bm.js realtime and `new WebSocket(`${proto}://${location.host}/ws`)` use) and whatever `csp.connect_src` declares. A page that opens a WebSocket to another host (a market feed, a speech-to-text socket, a model viewer) must declare it: `csp: {connect_src: "wss://ws-feed.exchange.coinbase.com"}`. Only a `wss://host` (or `ws://host`) source, or the `wss:` scheme, allows a WebSocket; an `https://host` source does not. `benmore check` and the post-write check warn about a `ws://`/`wss://` literal host in static/ that csp.connect_src does not cover, naming the file and line and the app.yaml line to add.
