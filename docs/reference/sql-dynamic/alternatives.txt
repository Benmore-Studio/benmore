For value-only substitutions (the common case), `run: sql` + `:name` / `${{ }}` placeholders covers it parametrized. If the request picks an identifier (sort column, direction), keep the SQL parameterized and choose among fixed literals: `ORDER BY CASE :sort WHEN 'name' THEN name WHEN 'created' THEN created_at END` in a `run: sql` step, or one `if:` branch per allowed shape. There is no `trusted:` opt-out - a request-sourced ref in sql_dynamic text is always refused. sql_dynamic is the right answer only when server-side code (an LLM step, admin tooling) authors the SQL.
