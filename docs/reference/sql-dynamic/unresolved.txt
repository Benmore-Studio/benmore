A reference in a sql_dynamic query that has no value fails the step before the statement runs, with `unresolved template reference(s) in step "<id>": <reference>` and a hint. When SQLite cannot read a token of the rendered statement, an admin's step_error reads `sql_dynamic: unrecognized token: [redacted]`: the token is redacted because sql_dynamic text can hold env values and row data, and the hint names the usual causes. A step's output is `${{ steps.<id>.outputs.<column> }}` (the first row's column) or `${{ steps.<id>.outputs.rows }}`; `{{steps.<id>.<column>}}` without `outputs` is never filled in.
