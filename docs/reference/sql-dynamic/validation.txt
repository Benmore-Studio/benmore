Write time, `benmore check` and flow load refuse a sql_dynamic query that text-interpolates a bare `{{name}}` or `:name` (the request-param shape) wherever the step sits: top level, `if:` steps/`else:`, `for_each:` and `parallel` bodies, and `on_error:` handlers. In a request flow the write gate and `benmore check` also refuse a caller-written profile value (`${{ user.first_name }}`, any `user.<col>` but the framework's account columns) and `${{ user.email }}`, and flow load logs it. Namespaced refs (`{{ steps.<id>.outputs.<field> }}`, `{{ env.X }}`) pass the static check; the runtime taint guard separately refuses request-sourced values.
