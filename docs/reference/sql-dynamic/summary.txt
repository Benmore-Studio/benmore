`run: sql_dynamic` is the opt-in escape hatch for queries where `{{ ... }}` must be substituted as RAW SQL TEXT rather than bound as a parameter. The motivating case is an AI agent generating SQL at runtime - the framework cannot bind a query STRING into itself, only values into placeholders. This step type ships that flexibility with explicit injection risk. The SQL may be built only from values the server controls: a model's answer to a prompt that reads request input is request input, and the step refuses it (see never_use_for).
