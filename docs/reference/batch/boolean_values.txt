Single/batch create, PATCH, transaction writes and NDJSON ingest accept JSON true/false for declared Boolean columns and normalize them to 1/0 before validators and hooks. Batch PATCH fields accept native JSON booleans and numbers. Explicit null clears a nullable field; omitting a key retains the current value or create default. Prisma required scalars refuse explicit null; SQL-only create paths retain their legacy omission behavior. See schema.scalar_writes.
