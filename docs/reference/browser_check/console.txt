`console` also carries the browser's own security messages, marked `source: "security"`: a Content Security Policy refusal (`Refused to connect to 'wss://...' because it violates ... connect-src ...`) or mixed content. Chrome prints these itself rather than through console.*, so a page whose WebSocket the CSP blocked shows the refusal here. A URL in such a message loses its query string, as in failed_requests. A refusal is level error, so browser_batch and `benmore verify` count it as a console error; a report-only policy's message (`[Report Only] ...`, which blocks nothing) is level warning. Other browser messages (network, deprecation, interventions) stay out: failed requests have their own list.
