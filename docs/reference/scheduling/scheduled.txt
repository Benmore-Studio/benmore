POST /api/_scheduled { kind:'reminder'|'flow', title?, message?, flow?, body?, table?, row_id?, run_at } (run_at: RFC3339 or a duration like '2h'; row_id: a string or an integer, stored as text). GET /api/_scheduled?table=&row_id= (yours; includes status and last_error). DELETE /api/_scheduled/{id} cancels your pending or blocked task and answers what is stored: 200 {status:'cancelled'} only when this request cancelled it; 409 {error:'scheduled task already <status>', status} when the task is yours but running, done, failed or already cancelled (nothing changes; a client that only needs the task not to run can treat status 'cancelled' as success); 404 {error:'scheduled task not found'} for an id that does not exist or belongs to another user (one answer for both, so ids cannot be probed); 500 when the write failed. bm.api.delete throws on the 404 and 409 with err.status and err.body.status; the Reminder and ScheduleAction components show the message and re-read the list (an already cancelled task raises no error).
