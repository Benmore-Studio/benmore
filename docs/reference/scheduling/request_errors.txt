A body POST /api/_scheduled or /api/_approvals cannot read answers 400 naming the problem: `row_id must be a string or an integer`, `"title" must be a string, not a JSON number`, `request body must be a JSON object`, and on /api/_scheduled `run_at required: ...` only when run_at is missing. A flow the caller may not schedule answers 403 in the caller's terms (`you do not hold the role this flow requires`, `your credential lacks the permissions this flow requires`, `no flow with this name exists`); `task owner no longer has the flow's required role` is the reason a blocked task's last_error carries when the owner loses the role later.
