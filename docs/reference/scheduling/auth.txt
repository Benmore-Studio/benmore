Every endpoint needs a signed-in caller. Writes (POST/DELETE /api/_scheduled, POST /api/_approvals and /decide) need the CSRF token from a cookie session (without it: 403 `invalid CSRF token`); a Bearer-only request (session or API token, no session cookie) needs none. kind:'flow' needs a direct login session (see flow_authorization), so an API token can schedule reminders but not flows. See api({at:'csrf'}) → bearer_exemption.
