Robust, safe Markdown → HTML. Server-rendered by the benmark engine (github.com/benmore-studio/benmark, built on goldmark): CommonMark + GFM (headings, tables, task lists, strikethrough, autolinks, nested lists), syntax highlighting, ```mermaid``` diagrams, media embeds (video/audio/PDF/YouTube/Vimeo), heading anchors, wikilinks, and front matter. Sanitized by default (bluemonday) - safe for innerHTML. `bm.markdown(text)` POSTs /_internal/markdown; `bm.markdownBatch(items)` renders a whole list in one round-trip.
