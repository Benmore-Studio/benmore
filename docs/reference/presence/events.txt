p.onChange(fn) fires on the SSE event {table:'_benmore_presence', action:'insert'|'delete'} after a join, and after a leave or sweep expiry that removed a member (it names no slug or user, so re-fetch members()). A leave by a caller who was not present changes nothing and sends no event. Delivered to signed-in streams; in an app with `groups:` a join or leave reaches only the caller's tenant (and admins), a sweep reaches every signed-in stream. A generic {action:'refresh'} also fires it. On `/ws` the same event arrives as {type:'change', table:'_benmore_presence', action}; a connection that sent a table `subscribe` gets it when the subscribe names `_benmore_presence`.
