p.onChange(fn) fires on the SSE event {table:'_benmore_presence', action:'insert'|'delete'} after any join, leave or sweep expiry (it names no slug or user, so re-fetch members()). Delivered to signed-in streams; in an app with `groups:` a join or leave reaches only the caller's tenant (and admins), a sweep reaches every signed-in stream. A generic {action:'refresh'} also fires it.
