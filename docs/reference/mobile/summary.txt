`benmore mobile <app> [--platform ios|android|both] [--dir DIR]` scaffolds a Capacitor native-WebView wrapper pointing at the deployed app's live URL. The output is a working npm project - `npm install && npx cap add ios && npx cap open ios` lands you in Xcode with a buildable .ipa shell. Frontend changes ship via the normal `benmore push` flow because the wrapper's WebView loads the live URL - no parallel codebase, no separate build step. Rebuild only when `capacitor.config.ts` changes (plugins, icons, splash).
