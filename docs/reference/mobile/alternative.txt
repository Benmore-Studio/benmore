PWA via a `pwa:` section in app.yaml (see `pwa`) is also installable on iOS + Android via 'Add to Home Screen' - no developer account, no review. An install prompt needs a manifest icon that loads: set `icon`, or see `pwa` for what the manifest lists without one. Right answer for 80% of apps. Use the Capacitor wrapper when you need App Store presence or native plugins (push notifications, camera, biometrics).
