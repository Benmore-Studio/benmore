Capacitor's plugin ecosystem works out of the box. Install via npm (`npm install @capacitor/camera`), tell native about it (`npx cap sync`), add iOS Info.plist usage strings (NSCameraUsageDescription etc.), use from TSX via `import { Camera } from '@capacitor/camera'`. Detect the environment with `Capacitor.isNativePlatform()` - fall back to the web equivalent in a regular browser. Common plugins: camera, geolocation, push-notifications, share, haptics, local-notifications, preferences, filesystem, keyboard, status-bar.
