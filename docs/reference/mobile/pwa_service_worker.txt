`/sw.js` is reserved: the framework serves a generated worker there before any app route, so a `static/sw.js` never runs at the root scope (one served from `/static/sw.js` only controls `/static/`). An offline-first app opts in with `pwa:
  service_worker: /static/sw.js` - `/sw.js` then serves that file (read per request, `Cache-Control: no-cache`). It must be a `.js` file inside `static/` (symlink-safe); anything else logs once and falls back to the generated worker. With a reviewed `mcp.yaml` it is served from the reviewed source captured at the last successful load, like every `/static/` file, never from later disk edits. Apps without the key get the generated worker. A Capacitor shell that loads `server.url` uses the same worker, so this is what lets it open with no connection.
