Framework-built table reads decrypt only configured encrypted source columns: CRUD/readbacks, relationship includes, workflow reads, version history/as_of/revert, direct _query projections, account data exports and signed-file record checks. Ordinary TEXT stays literal even when it begins enc:v1:/enc:v2:. Grouped/aggregate outputs are not interpreted as encrypted source columns. V2 ciphertext must authenticate the known source table and column; v1 remains readable, and historical rows use their original source table. Existing role/tenant masking, hidden fields and private connector read limits still apply. This bounded repair does not change generic authored SQL decoding or every framework metadata API; those remaining read paths must not be assumed source-aware. Gotmpl `queries:` and mustache `<query>` tags do not use it (authored_page_queries).
