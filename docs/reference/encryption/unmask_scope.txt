Unmask authorization is evaluated per row. A tenant membership role or tenant-scoped grant can unmask only rows in the caller's effective tenant (the groups key, or id on the configured tenant-root table), and explicit groups.shared reference tables. It cannot unmask an ungrouped, non-shared table or a projected row whose tenant cannot be established. Matching primary/global role grants remain global; admin act-as and connector tenant limits still apply. The self/owner rule uses the row's own user_id, including historical snapshots. Blind-index searches and encrypted-field query operations honor the same scope instead of treating tenant roles as global.
