Field-level AES-256-GCM encryption at rest, configured via encrypted.yaml or app.yaml. INSERT/UPDATE triggers seal plaintext with table/column AAD; benmore_encrypt_plaintext(value, table, column) always treats non-NULL input as plaintext, including enc:v1:/enc:v2: literals. Existing benmore_encrypt remains prefix-idempotent for compatibility. Trigger installation is transactional and app load fails if the replacement cannot be installed. Reads decrypt only for allowed roles and mask for others. blind_index provisions equality-searchable HMAC siblings; INTEGER/REAL encrypted columns round-trip as numbers.
