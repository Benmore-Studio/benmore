Native writes treat submitted enc:v1:/enc:v2: strings in configured encrypted fields as plaintext, even if the string is authentic ciphertext from another row. Single/batch/transaction create/update, ingest, Mode A import and tenant bootstrap seal the literal text after the ordinary gates; before-hooks see the original input and blind indexes use its literal bytes. Rows already stored are not rewritten. Trusted storage SQL, trigger recursion and key rotation retain their ciphertext-idempotent behavior. This write rule does not change generic SQL decoding or decryption of prefix-looking values from ordinary unencrypted columns.
