`run: transcribe` turns audio into text inside a flow - no vendor, no API key. The step decodes the input to 16kHz mono WAV with `ffmpeg` and runs local Whisper inference with `whisper-cli` (whisper.cpp), both shelled out to prebuilt HOST binaries. Every edition ships it (OSS/self-hosted apps get local transcription too); it needs those two binaries + a ggml model present on the host.
