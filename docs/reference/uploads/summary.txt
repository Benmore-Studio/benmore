Multipart file upload via POST /api/_upload. `kind=files` (default) → PUBLIC; `kind=private` → PRIVATE (signed-URL only). `private` and `public` match in any letter case; any other kind is a PUBLIC folder, and one that names private in another spelling (`private-docs`) answers 400. The framework returns the stored reference: a CDN URL when the platform media backend is active, else a local /uploads/<path>. Either way, reference it as-is - render public refs directly, and read private ones with bm.signedUrl or a serve_file flow (see below).
