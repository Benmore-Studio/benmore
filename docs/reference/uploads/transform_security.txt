Local signed URLs are bound to the exact host and must be renewed after this upgrade. Image transforms authorize the source before cache lookup; private originals and derivatives use no-store. Public derivatives are cached outside uploads, capped at 64 MiB and 256 entries per app; a full cache still serves uncached transforms. A transform is refused with 415 when the decoded source, the resize buffer (output width x source height x 32 bytes) and the encoded output would together exceed 512 MiB, and transforms in flight share that budget (a request that does not fit beside them waits). Legacy /uploads/_transforms paths are unavailable; request derivatives through /api/_images/transform.
