Task recipes: complete, minimal apps for the things agents are most often asked to build. Each key holds every source file of a small working app, how to check a copy of it, what to watch for, and the reference keys for each part. The files are the ones the framework's own test run executes, so they work as written: copy them, rename the tables and fields, keep the shape. `multi_tenant`: organisations, members with roles, rows scoped to the tenant. `owner_records`: owner-only rows a manager also sees, with a private file per row. `public_form`: a rate-limited public form that stores a row and emails the owner. `inbound_webhook`: a signed webhook, recorded once, that queues background work. `scheduled_sync`: an hourly paginated import that fails when it stores nothing. `status_workflow`: role-guarded status changes with a history members can read.
