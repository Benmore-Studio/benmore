Password-reset, email-verification and email-change links are built from app.yaml seo.url, else BENMORE_PUBLIC_URL (or the first concrete CORS_ORIGIN) - never from a client-supplied Host header. Hosted apps also accept the request host the platform vouches for. A self-hosted app with none of these configured does not send the link: forgot-password still answers with its generic success, signup skips the verification email, email change fails with an error, and the server logs `SECURITY: not sending a credential email ...` naming the setting to add. Set seo.url (or BENMORE_PUBLIC_URL) to the app's public https origin.
