Where a form post lands once it has signed someone in (303): `POST /signup` goes to `auth.signup_redirect`, else `auth.redirect`, else `/`, and does not read `next`. `POST /login` goes to the form's `next` when that is a path on this site (one leading `/`), else `auth.redirect`, else `/`. `auth.signup_redirect` applies only when sign-up itself issues the session: with auth.otp, auth.require_verified or a role that must enroll MFA it issues none and answers with that step instead (`step_pages`). A request that asks for JSON (`Accept: application/json`, or a JSON body) gets 200 `{ok: true, user}` and no redirect.
