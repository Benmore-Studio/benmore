POST /settings/password {current_password, new_password, confirm_password, _csrf} (a request with Accept: application/json gets {ok, message} or {ok:false, error} instead of a redirect to the settings path) replaces the password and, in the same transaction, revokes every other session, every API token (bmr_ and bma_), pending OAuth authorization codes, every MCP connector grant with its pending consents and codes, unused reset links and a pending email change. Only the session that made the change stays signed in; API clients must mint new tokens afterward. Passkeys stay unless the form sends revoke_passkeys=1.
