`features.account_settings: false` disables optional account self-service: profile writes, user directory, password/email-change/delete settings, email confirmation, own-session listing/revocation and MFA/passkey enrollment, management and removal. It leaves GET /api/_auth/profile, password/passkey login, logout, CSRF, session issuance, login-time MFA verification and required password replacement available. The default is enabled. Email changes must satisfy auth.domain/auth.allow_emails both when requested and again when confirmed.
