`benmore revoke-session <app> <session-id> [--env dev|prod]` (MCP revoke_session; editor access) ends one end-user session of the instance at once. `<session-id>` is the stored id (`sha256:...`, as the audit log and a SQL read of _benmore_sessions show it; see session_storage) or the session token itself. The answer's `ok` is true when a session was ended. With no `--env` and no pin the CLI targets prod once the app has a prod instance, else dev.
