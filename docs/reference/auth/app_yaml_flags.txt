Boolean auth keys (require_verified, verify_email, otp, oauth_only, read_audit_sync, passkeys, signup, password_reset, api_tokens) take true/false, and yes/no, on/off, 1/0 mean the same. Any other value is refused at write time. The write gate checks auth: keys however the block is laid out (indent, flow mapping, comments). `auth.mfa` and `auth.oauth` have no effect and are refused: require MFA with `require_mfa_for_roles`, configure providers with top-level `oauth:` (api(at:"oauth")).
