SSR pages can render `<transitions table="orders" id="{{id}}">`: buttons for the transitions the signed-in viewer may take from the row's current state, the same list GET /api/<table>/<id>/transitions answers (role, `when:` and a command-owned state column all count). The row is read through the table's read mode and row scope, so a record the viewer can't read (another tenant's or owner's) renders nothing.
