A workflow that declares `timeout:` may not use an encrypted column as its state column: a timeout finds its rows by the stored state value, and an encrypted column stores ciphertext, so no timeout would fire. The write gate and `benmore check` refuse the combination, whether workflows.yaml or encrypted.yaml / app.yaml `encrypted:` is the file written (a deployed file still loads and logs a warning). Transitions without timeouts read the decrypted state and work on an encrypted column.
