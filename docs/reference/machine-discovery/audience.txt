Every generated docs surface (/api/_docs, /docs, /docs?format=md, the OpenAPI document and aliases) is filtered PER CALLER: an admin on an unscoped credential (a sign-in, or an API token with full scope) sees every table, route and page; an admin's SCOPED API token (e.g. notes:read handed to an integration) is filtered like everyone else; everyone else sees only tables whose read gate they pass (access mode + token scope), only the CRUD operations whose own access mode they pass, and only pages they could open. One public table does not publish the rest of the schema. /api/_schema is per-user too, and lists tables the caller can do nothing with only to an admin on an unscoped credential; a field's `relation` (and a table's `children`) name only tables it lists. `benmore verify` checks the full contract.
