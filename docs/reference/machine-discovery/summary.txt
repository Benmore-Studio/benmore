With docs enabled, each deployed app serves one OpenAPI 3.1 document at /api/_openapi, /openapi.json, and /api/openapi.json (same body and headers), filtered per caller. Sign-in is required unless the app has a table readable by `anon` or `everyone`; then an anonymous caller gets the document limited to those tables' read routes. `features.docs: auth` requires sign-in regardless. Each app serves its own /llms.txt (and the byte-identical /.well-known/llms.txt): the app's `static/llms.txt` when it ships one, otherwise a generated list of its public pages. /llms-full.txt exists only when the app ships `static/llms-full.txt` (404 otherwise). `features.docs: auth` puts all three behind sign-in. Benmore's own documentation index is https://benmore.ai/llms.txt and /llms-full.txt.
