Taking payments in an app via Stripe. TWO paths: (1) Stripe Connect (hosted platform) - the app owner clicks Connect Stripe in dashboard → Payments (or /platform/stripe/connect), completes Stripe-hosted onboarding, and STRIPE_SECRET_KEY / STRIPE_PUBLISHABLE_KEY / STRIPE_ACCOUNT_ID land in the app env automatically with TEST keys in the dev environment and LIVE keys in prod - flows using ${{ env.STRIPE_SECRET_KEY }} are env-correct by construction. (2) BYO keys - `benmore env <app> set STRIPE_SECRET_KEY=sk_test_... --env dev` (and sk_live in prod) works as always. The connected account is a full Standard Stripe account the OWNER controls (their dashboard, payouts, disputes) - and can itself enable Stripe Connect for marketplace apps (sellers/couriers under the app's own account).
