Computed columns: columns whose value the database derives, declared in computed.yaml. `expr:` computes a column from the other columns of its own row; `sql:` with `triggers:` keeps a value on a parent row that follows its child rows (a count, a sum). They are recalculated inside the database on every write, whichever path makes it (auto-CRUD, a flow, a hook, raw SQL), and a client can never write them.
