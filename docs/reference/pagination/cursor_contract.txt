cursor is the last row's raw id, not base64. Start with cursor=0 for integer IDs (it also starts a UUID-id table: text ids compare above '0'). Returns {data,next_cursor,limit}; next_cursor=null means exhausted. Filters and scoping apply on every page; fields projections may omit id without losing next_cursor. Ordering is id ASC. limit defaults to 20 on a cursor page (an offset list defaults to 50) and is capped at 500.
