Owner rank comes only from the app's owner. Collaborators are editor or viewer; a collaborator recorded with role 'owner' counts as an editor. Ownership moves only through a transfer, which the recipient accepts, which counts against the recipient's app limit and which needs a recipient plan that includes the paid features the app has (see `plans`). A transfer carries the app's code, data, environment variables and secrets, custom domains, email sending domains, managed DNS, dedicated SMS number and collaborators (the previous owner stays as an editor); it does not carry a Stripe Connect connection, which is disconnected on acceptance unless the new owner connected the same Stripe account on an app of their own (see api({at:'payments'})), and it switches the GitHub mirror off unless the new owner linked it themselves (see api({at:'github'})). A viewer reads logs without the app's end users' identities: the concise audit log, read audit, request logs, client errors, recent activity and tail_logs, on MCP and the dashboard, replace end-user emails and IP addresses ([email], [ip]; users appear by id) and mask them inside log lines, paths and error text, and filtering by an end user's email needs editor. Promote a collaborator to editor when they need those identities. The dashboard's backup list and security-scan results need editor too, as the MCP tools for them do.
