check_app (and `benmore check`) run the source checks and the live checks (the app's last reload of its source, unapplied schema changes, schema drift). The live checks only read, so every collaborator gets them, a viewer and an apps:read connection included. When the app does not answer (stopped, crash-looping, quarantined) the report carries an error finding (source app_live) and live_database_checked:false, so it is not clean and `benmore check` exits 1: read the app's logs (tail_logs) and its recent pushes (git_log) before restarting it.
