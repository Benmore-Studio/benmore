DownloadMyData(target, {label?}) downloads the signed-in user's own data as my-data.json from GET /api/_my-data, the framework's data-access (DSAR) export: {exported_at, user_id, email, profile, tables, audit_log}. `profile` is the user's _benmore_users row without credential columns; `tables` has, for each table with a user_id column the user may read, every row whose user_id is theirs and that they can still read (all of them, no page cap; rows of tables they reach only through a tenant, membership or share are not included); `audit_log` is their latest 1,000 audit events (table, row_id, action, time; no row values). It needs an ordinary signed-in session (an API token, act-as or a support session gets 403), and `features.exports: false` in app.yaml answers 404. On any failure the component downloads nothing and shows an error toast saying so. For an export of everything a user can read, use ExportButton per table.
