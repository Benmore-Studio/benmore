Schema-driven UI components (about 140). Framework-owned, served at /_internal/sdui.js, auto-mapped into every app's import map - `import { DataTable, RecordForm } from 'sdui'`. They render from /api/_schema (the per-user descriptor: control per field, masked/writable, allowed ops) the same way auto-CRUD renders from the schema, so the FRONTEND is as deterministic as the backend: add a column → push → it appears with the right control + cell. Zero per-column app markup. Data components are `Name(target, opts) → {destroy, refresh?}` and live-refresh on bm.live events; overlays (Modal, Drawer, Toast, CommandPalette), Gate (a boolean) and the HTML-string atoms differ, as listed below.
