Behavior is fixed; PRESENTATION is a swappable skin registry. registerSkin({ button, input, field, table, th, cell, ... }) restyles the FORM/TABLE primitives (DataTable/RecordForm/forms) - each returns an HTML string. The standalone components (Stepper, KpiTile, Alert, Modal, Gauge, CommentThread, …) instead read THEME TOKENS so one setting brands them all: setAccent(color, textColor?) sets --bm-accent (buttons/links/active states/sparkbars/dots); button sizing reads --bm-btn-px / --bm-btn-py / --bm-btn-fs / --bm-btn-radius (set them in :root to match your button system). Default skin is Tailwind + semantic data-bm-* hooks. Together: registerSkin (primitives) + setAccent + --bm-btn-* tokens = full brand coverage with no per-component overrides.
