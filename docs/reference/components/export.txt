ExportButton(target, {table, columns?, where?, q?, filename?, label?, maxRows?}) downloads every row the caller can read as CSV, in id order, by walking the list API's keyset pages (`?cursor=`, 500 rows each) with the same where/q filters and access rules on every page. It stops at maxRows (default 50,000, 100 requests against the app's per-minute request budget; `limit` is accepted as an alias) and then shows a warning toast naming how many rows it exported and how many match. Cells starting with = + - @ get a leading ' (spreadsheet formula injection).
