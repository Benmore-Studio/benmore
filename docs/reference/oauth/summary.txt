MANAGED MODE (hosted platform): Google/Microsoft sign-in works with ZERO setup - no client IDs needed. The platform holds shared provider credentials; /auth/google just works on every app (the consent screen shows the platform identity, like Lovable Cloud managed mode). BYO credentials (<PROVIDER>_CLIENT_ID/_CLIENT_SECRET env) always take precedence and white-label the consent screen. Configurable OAuth providers (Google, GitHub, Microsoft, custom). The callback URL is built from r.Host - never hardcoded. Managed sign-in is bound to the initiating browser: /auth/<provider> sets a short-lived HttpOnly nonce cookie, and a sign-in finished in another browser is refused (login CSRF).
