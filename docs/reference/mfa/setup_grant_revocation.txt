MFA setup tokens are tied to the account's current credential generation as well as the app, account and expiry. Changing or resetting the password invalidates earlier setup tokens for both setup and verification, including resets that write the same temporary password. Startup installs the required revocation state automatically; setup-token enrollment fails closed if it is unavailable. Verification rechecks the grant and commits factor activation and session creation together. An upgrade rejects older setup tokens without this binding; sign in again to restart enrollment. No enrolled factor is removed by this format upgrade.
