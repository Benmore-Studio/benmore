Under compliance: hipaa reads of every table are audited unless auth.read_audit names the tables, each event is written before the read answers (auth.read_audit_sync cannot be turned off), and a read whose audit row cannot be written answers 500 instead of the rows (fail closed). auth.read_audit must then be "*" or a non-empty comma list of table names: `false`, `,` or an empty entry is refused by the write gate, `benmore check` and the loader, a name the schema does not declare by the write gate and `benmore check`, and at run time a listed name that is no table makes every table audited. Anonymous reads of a table whose read mode is anon/everyone are not recorded (public data). Cost: every audited read is a database write and waits for SQLite's single write lock, so a long bulk import (no time limit) or a transactional flow delays reads, and a read that waits out the busy timeout answers 503 `database_busy` with a Retry-After header instead of the rows (see api({at:'errors'}) common_envelopes). Coverage, actors and the client address: api(at:"audit") -> read_coverage.
