`benmore focus [repo] [--from DIR] [--agent codex|claude|none] [--list] [--print] [--clear] [--json|--no-json]` is an optional, local helper for coding in one repository with one nearby repository as read-only context; ordinary sessions do not use it and it sends nothing to the platform. The coding repository is the Git root at or above `--from` (default: the current directory). Candidates are its parent directory, its sibling directories and its direct child directories that are Git repositories; hidden directories and paths holding control characters are left out. `--list` prints the candidates. `repo` picks one by its number in that list, its name, or its relative or absolute path; an unknown or ambiguous one exits 2, and with no `repo` the command asks on an interactive terminal and exits 2 otherwise. With no candidate at all it exits 5. `--print` prints the instruction prompt for the pair and writes nothing. Otherwise the choice is saved to `.benmore/focus.json` in the coding repository (work_repo, context_repo, prompt, updated_at) and the agent is started there with the prompt: `--agent`, else BENMORE_FOCUS_AGENT, else the first of `codex` and `claude` on PATH; its environment carries BENMORE_FOCUS_WORK and BENMORE_FOCUS_CONTEXT. `--agent none`, no agent on PATH, or JSON output (`--json`, or a stdout that is not a terminal unless `--no-json`) saves the file and prints the result without starting an agent. `--clear` removes the saved file.
