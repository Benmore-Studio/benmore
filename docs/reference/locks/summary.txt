Pessimistic record locking. Acquire → operate (renewing every ~20 s) → release. A lock lasts 30 s from its last acquire; the holder renews it by POSTing again. A lock held by another user answers 409 Conflict. Acquiring a lock (POST /api/<table>/{id}/lock) requires EDIT rights: the table's update mode and the row's edit scope (view access is not enough, since a lock blocks other editors).
