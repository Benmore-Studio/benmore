Read-audit and runtime usage buffers belong to their originating app, including when multiple apps share a process. They retain pending entries across worker replacement on reload and flush on graceful shutdown before SQLite closes. This is not durable queueing: a crash, forced termination, or database write failure can still lose buffered entries. Usage at GET /api/_usage is app runtime counting for the caller's scope (group, else user), separate from hosted billing and agent token accounting; its app-wide total_rows and storage_bytes gauges are returned only to an admin with an unscoped credential. Scheduled backup workers stop on reload/shutdown; an in-progress tracked snapshot and the startup context-graph rebuild drain before database close.
