GET /api/_audit/reads requires authentication. Ordinary users see only their own read events, ignoring a user_id filter; an unscoped admin can filter another actor. Filters table, row_id and user_id remain parameterized. Limit defaults to 100 and must be an integer from 1 through 1000; invalid, zero, negative and oversized values return 400 before buffered writes or querying. This endpoint returns event metadata, never the read rows' field values.
