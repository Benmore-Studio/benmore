POST /api/_auth/impersonate {user_id, password} (password = the admin's own, as re-authentication) starts a 1-hour support session as a non-admin user. It needs a global admin on an unscoped credential (a scoped API token or Bearer session gets 403); a roles: block that does not define `admin` does not block the admin's own sign-in. Targets holding the admin role (primary role or a global admin grant) are refused with 403. Every audit row written through that session keeps user_id/user_email = the impersonated user and adds impersonator_user_id/impersonator_email = the admin who acted, read from the support session's own row. Filter on impersonator_user_id <> 0 to review support activity. The impersonated user's own session list (GET /api/_auth/sessions) does not show the support session. The support session works only while the admin who started it is still an active admin: if that account is demoted, deactivated, deleted or put on a temporary password, the session stops resolving at once instead of running out its hour. It also ends with the admin's sign-in that started it and with any revocation of the admin's credentials: `api(at:"auth")` → `support_sessions`. A support session (and a session platform tooling minted to act as the user) sees and does what the user can in the app, but it does not manage the account's credentials: GET and DELETE /api/_auth/sessions, DELETE /api/_auth/api-tokens/{id}, DELETE /api/_auth/oauth-tokens/{provider}, an `email` change through PATCH /api/_auth/profile or POST /settings/profile, POST /settings/password and POST or DELETE /api/_devices (a registered device keeps receiving the account's push notifications) answer 403, before the account's password is looked at (so those forms cannot test guesses or lock the owner out). Creating an API token, MFA, passkeys, account deletion, connector consent and the emailed-link confirmations refuse it too. Still allowed: reading the profile, listing API tokens, connected providers and passkeys (names and dates, never secrets), and editing ordinary profile fields.
