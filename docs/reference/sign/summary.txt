Sign / authenticate outbound HTTP calls on a `run: api` step. One declarative shape covers AWS sigv4, Stripe-style webhook HMACs, OAuth client_credentials (with TTL-cached bearer) and plain bearer; an HS256 JWT can be assembled inline with the `hmac_sha256` and `base64url` pipes (there is no RSA or ECDSA pipe, so RS256/ES256 JWTs are not supported). Two forms: 'recipe: <built-in>' + bindings, OR inline `compute:`/`headers:`/`before:`/`query:`.
