The renderer runs page script with the JavaScript JIT off, on every host: script still runs, more slowly, and WebAssembly does not. It composites in software only, so WebGL canvases print empty. What a 501 means: `renderer_crashed`, Chrome or a child was killed by a signal (a fatal check in Chrome, the service's memory limit, a thread its task limit refused); `renderer_failed`, Chrome exited with an error status; `renderer_start_failed`, the binary could not be started; `renderer_no_output`, Chrome exited without a complete PDF. The `PDF ERROR [<page>]` line in `benmore logs` carries Chrome's own FATAL line, which names the cause; report it with the request id.
