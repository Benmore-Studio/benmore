When Chrome is installed but cannot produce the PDF, GET /pdf/<page> answers 501 `PDF generation unavailable - <reason> (request id: <id>)` with header `X-Benmore-PDF-Unavailable: <reason>`: `renderer_start_failed` (Chrome could not be started), `renderer_crashed` (killed by a signal: an abort, a crash, the service's memory or task limit), `renderer_failed` (exited with an error) or `renderer_no_output` (exited without a complete PDF). Nothing in the request fixes these; retry later or report the request id. Chrome's own output (its fatal line and stack, temporary paths, flags) is only in the app log (`benmore logs`, the `PDF ERROR [<page>]` line) and the request error record, also for dev-mode apps. A render that takes over 30 s answers 504 `PDF generation timed out`.
