Generated types (/_internal/types.d.ts and /_internal/bm.d.ts) and the per-caller flow registry (/_internal/flows.json) send private/no-cache/no-store origin directives, Vary: *, and CDN no-store headers on both successful and refused responses. Generated types keep their admin/types-token gate; the registry is filtered per caller. GET and HEAD, including percent-encoded spellings of the same path, share these directives. The public framework modules /_internal/bm.js and /_internal/sdui.js send Vary: * with their no-store and ETag headers on 200/304 responses. SDK and FlowForm registry requests use `cache: no-store`, so the browser's HTTP cache is not reused for them. Origin headers do not override a CDN's own cache rules: a CDN you put in front of the app must bypass caching for these routes, in every equivalent path spelling.
