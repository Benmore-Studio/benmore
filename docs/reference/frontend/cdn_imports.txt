Prefer the /_internal/ libraries (no third-party origin). When a module must come from a public CDN, import it by its full URL in source (`import { h } from 'https://esm.sh/preact@10.23.2'`, or an import map / `<script src>` in static HTML): the page CSP allows unpkg.com, cdn.jsdelivr.net, esm.sh or cdn.skypack.dev only for an app whose files name that host, so a URL assembled from data or env needs `csp: script_src`. Pin exact versions. See api({at:'csp'}) → script_cdns.
