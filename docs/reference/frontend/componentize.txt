esbuild runs with bundle:true, so SPLIT the UI into focused modules and import them - don't grow one giant app.tsx. Put pieces in static/components/*.tsx + static/lib/*.ts and `import { X } from './components/X'` (relative imports resolve .tsx/.ts and bundle into app.js; the compile cache tracks every imported file's mtime). Every import must resolve inside static/: the bundle is public, so an import that reaches outside it (for example '../env.yaml') is refused at push (see compile_errors). Push an imported module before the file that imports it. Keep files ~300 lines; app.tsx is a thin entry. A monolith is one multi-minute write that can hit the output cap, and huge-file edits mismatch more - small modules are faster + more reliable to write AND edit.
