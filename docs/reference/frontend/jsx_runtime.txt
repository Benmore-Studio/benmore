The framework ships no React, ReactDOM, JSX runtime, `bm/ui` module, `bm.mount` or `bm.useTable`/`useRecord`/`useAuth` hooks, and no React window globals (loading bm.js sets window.bm, nothing else); only `bm` (/_internal/bm.js) and `sdui` (/_internal/sdui.js) are external imports. JSX compiles against react/jsx-runtime, so a bundle with JSX elements builds only when that module resolves to a file under static/ (for example a tsconfig.json `paths` entry pointing at a vendored runtime); otherwise it fails with `Could not resolve "react/jsx-runtime"`. Write UI with DOM APIs, bm.html`...` templates and sdui components, read and write with bm.table(t).list/get/create/update/delete, refresh with bm.live(t, cb) or bm.query.invalidateTable(t). The write gate's antipattern messages name these APIs, and api() reports frontend_stack `tsx` for an app with static/app.tsx (or src/app.tsx).
