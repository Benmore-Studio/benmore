Keep verification light - favor a fast dev loop. After building: check_app (schema/config errors), probe_route the main routes + APIs (404 = route/file missing; pass as:<email> for auth-gated routes), and sql to confirm data shape. If a page looks broken or the user reports an issue, get_errors returns grouped browser/server failures with stack context, breadcrumbs and request IDs (bm.js auto-captures uncaught JS errors + failed same-origin requests). Fix what you find and move on.
