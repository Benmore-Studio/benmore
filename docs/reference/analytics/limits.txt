The browser beacon does not queue durable retries. Browser delivery failure, absent consent or rejected writes can leave gaps; analytics are not a billing or audit ledger. Events are periodically pruned to the most recent 50,000 rows. Visitor rows (_benmore_visitors, which feed new vs returning) are pruned to the 100,000 most recently seen; the visitor cookie (_bm_vid) is accepted only in the form the framework issues (16 hex digits), any other value is replaced with a new id; the stored country is a two-letter code or empty.
