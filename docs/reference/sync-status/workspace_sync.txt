`benmore sync [--force]` pulls every app in the signed-in account's app list (`benmore apps`) into the Benmore workspace (`~/Benmore/<app>`, or the parent of `$BENMORE_HOME`): it creates the directory of an app that has none and refreshes the others as `benmore pull` does. Each app is pulled from its default instance (dev when it has one, else prod); `--env` is not accepted and a `benmore use` pin is not applied. A pull that the manifest guard refuses, or that fails, is reported and the remaining apps are still pulled; the command then exits 1. `--force` bypasses the guard for every app, as it does for `benmore pull`.
