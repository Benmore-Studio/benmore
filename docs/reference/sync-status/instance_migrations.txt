`instance_migration` is a migrations/*.sql file only the deployed instance holds that is its own record of applying the schema the workspace also has: its statements equal a workspace migration under another name, or it carries the runtime's generated name and header while schema.prisma matches. It is listed but is not drift (exit 0 if nothing else differs); the file's bytes are read and checked against the manifest first. Prod can hold such a file from an earlier schema-changing promote (see api(at:"environments") `promoted_migrations`); the next promote removes it. Any other remote-only migration stays remote_only.
