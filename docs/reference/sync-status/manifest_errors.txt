A failed manifest fetch says why. HTTP 401 means the platform rejected the token (a newer `benmore login` anywhere, a dashboard sign-out or a password change replaces it): run `benmore login`. HTTP 404 with the platform's JSON error means the signed-in account has no editable app by that name in that environment: check `benmore whoami` (BENMORE_TOKEN overrides the saved login), .benmore/app or --app, and --env. Only a bare 404 reports a platform without /platform/app-manifest. Other commands' HTTP 401 prints the same `benmore login` hint.
