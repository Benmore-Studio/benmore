Local/remote source safety for Benmore workspaces. The deployed app manifest is the primary remote source of truth; GitHub ahead/behind is secondary context only. `benmore pull` writes `.benmore/remote.json`, and `benmore sync-status` compares that last-known remote base against local files and the current deployed manifest. `benmore sync-status --all` checks every app pulled into the Benmore workspace (`~/Benmore/<app>`, or the parent of `$BENMORE_HOME`); a workspace elsewhere needs its own `benmore sync-status <dir>`. Agent completion requires exit 0.
