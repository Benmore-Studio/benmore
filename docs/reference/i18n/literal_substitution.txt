bm.t(key, vars) reads own dictionary keys, retaining a missing key as a string even for names such as constructor or __proto__. It substitutes {{name}} or {{ name }} once from own variables. Variable names, including dots, and replacement values, including dollar signs or placeholder-looking text, are literal data; missing variables keep their placeholder and empty translations remain empty. bm.t returns text, not sanitized HTML: use textContent or an escaping UI component to display it.
