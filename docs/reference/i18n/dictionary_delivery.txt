The dictionary endpoint returns the exact language's flat key/string JSON object, including an empty object for an empty dictionary; an unknown or removed language returns 404. Dictionaries are public app UI content, so do not place secrets in translations. The language name is matched exactly (`ES` is not `es`). Dictionary responses request no-store caching. With a reviewed `mcp.yaml`, translations come from the reviewed source captured at the last successful load, never from later disk edits.
