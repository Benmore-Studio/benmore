# Benmore API Reference

Benmore exposes two distinct HTTP surfaces. They serve different jobs and must
not be conflated: one is the **live per-app runtime** auto-generated for every
deployed app; the other is the **platform control plane** that manages apps,
branches, versions, env, and logs. This document covers both, in that order,
then the shared error format.

| Surface | Base | Generated by | Scope | Status |
|---|---|---|---|---|
| **Runtime API** (per-app) | `https://<app>.benmore.ai/api/*`, `/sse/*`, `/ws`, `/pdf/*` | The app binary, per deployed app | One app's data, auth, real-time | **Live.** Auto-generated from `schema.prisma` + `app.yaml`. |
| **Control-plane API** (`/api/v1`) | `https://benmore.ai/api/v1` | `api/openapi.yaml` (OpenAPI 3.1) | Apps, branches, versions, env, logs | **Contract.** The durable REST spec; Go handlers are a next step (see `../../api/README.md`). |

> Today's primary live programmatic surface for control-plane work is the
> curated **MCP server** at `https://mcp.benmore.ai/mcp` — the same capabilities
> reshaped as outcome-oriented verbs with OAuth and per-user audit. `/api/v1` is
> the durable REST contract those tools map onto; treat its operations as the
> specification, not as wired endpoints, until the README says otherwise.

## 1. Runtime API (per-app)

Every deployed app serves its own REST surface, auto-generated from the app's
Prisma schema and `app.yaml`. No app code is required; the conventions below
activate automatically when the relevant columns/config exist. Source of truth
for app builders is `api(at:<topic>)` (see `../../CLAUDE.md`).

### Auth model

Two interchangeable credentials, both resolving to the same per-app session:

| Mechanism | Use | Notes |
|---|---|---|
| Session cookie | Web (browser) clients | Set on login; CSRF-protected. |
| `Authorization: Bearer <token>` | Native / API clients | Token from `POST /api/_auth/token` (email+password exchange). Bearer requests bypass CSRF. |

CSRF: served HTML carries `<meta name="csrf-token">`; JS reads it once and sends
`X-CSRF-Token` on mutations. Brute force: 5 failed logins → 15-minute lockout.
Verified/deactivated/role gating enforced in `getSession()` and at every CRUD
handler via `checkScope()`.

### Auto-CRUD on `/api/{table}`

Generated for every table:

| Method | Path | Action |
|---|---|---|
| `GET` | `/api/{table}` | List (filter, sort, paginate). |
| `GET` | `/api/{table}/{id}` | Read one. |
| `POST` | `/api/{table}` | Create; returns the full inserted row. |
| `PATCH` | `/api/{table}/{id}` | Update. |
| `DELETE` | `/api/{table}/{id}` | Delete (soft delete → UPDATE if `deleted_at` column exists). |
| `POST` | `/api/{table}/batch` | Batch create/update/delete (multi-row). |
| `POST` | `/api/{table}/ingest` | Streaming NDJSON bulk ingestion (rate-limited). |

**Column-driven conventions** (activate when the column exists):

| Column | Behaviour |
|---|---|
| `user_id` | Owner scoping — users see only their own rows. |
| `deleted_at` | Soft delete: `DELETE` becomes `UPDATE`, reads auto-filter. |
| `updated_at` | Auto-timestamps + optimistic concurrency. |

**Request conventions:**

- **Pagination** — `?page=N&per_page=N` (offset) or `?cursor=X&limit=N` (keyset). True row count via `?count=true`.
- **Field selection** — `?fields=name,email`.
- **Idempotency** — `X-Idempotency-Key` header on `POST` prevents double-submits.
- **Optimistic concurrency** — send `_expected_updated_at` on `PATCH`; mismatch returns `409`.
- **Protected fields** — `user_id`, `role`, `password_hash`, `created_at` are blocked in CRUD writes.

**Per-row extras** (registered when the relevant config/columns exist):

| Method(s) | Path | Purpose |
|---|---|---|
| `POST`/`DELETE`/`GET` | `/api/{table}/{id}/lock` | Pessimistic record locking with auto-expiry. |
| `GET` | `/api/{table}/{id}/versions` | Content version history. |
| `POST` | `/api/{table}/{id}/revert/{version}` | Restore a prior version. |
| `POST` | `/api/{table}/{id}/transition` | Workflow state transition (state machines). |
| `GET` | `/api/{table}/{id}/transitions` | Valid next states for the current user. |
| `POST` | `/api/{table}/{id}/share` | Grant record-level access. |
| `GET` | `/api/{table}/{id}/permissions` | List record ACLs. |
| `DELETE` | `/api/{table}/{id}/permissions/{email}` | Revoke a record-level grant. |

Point-in-time reads: `?as_of=<timestamp>` on a versioned table.

### System endpoints (`_`-prefixed)

All under `/api/_*`, grouped by concern.

**Auth** (active when `auth:` configured in `app.yaml`):

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/_auth/token` | Exchange email+password for a Bearer token. |
| `GET`/`PATCH` | `/api/_auth/profile` | Read / update non-sensitive profile fields. |
| `GET` | `/api/_auth/sessions` | List active sessions (IDs SHA-256 hashed). |
| `DELETE` | `/api/_auth/sessions/{id}` | Revoke a session. |
| `POST` | `/api/_auth/mfa/setup` | Begin TOTP MFA enrollment. |
| `POST` | `/api/_auth/mfa/verify` | Verify a TOTP code. |
| `GET` | `/api/_auth/oauth-tokens` | List connected OAuth providers (tokens auto-refreshed). |

Protected profile fields: `id`, `password_hash`, `role`, `verified`,
`deactivated_at`. Password change invalidates all other sessions.

**Webhooks** (outbound subscriptions):

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/_webhooks` | Register a URL for create/update/delete events on any table. |
| `GET` | `/api/_webhooks` | List subscriptions. |
| `DELETE` | `/api/_webhooks/{id}` | Remove a subscription. |
| `POST` | `/api/_webhooks/{id}/test` | Fire a test delivery. |

Deliveries are HMAC-SHA256 signed, async (job queue + retry), SSRF-protected
(private/internal IPs blocked at registration and delivery).

**Notifications** (in-app inbox, `_benmore_notifications`):

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/_notifications` | List the current user's inbox. |
| `PATCH` | `/api/_notifications/{id}/read` | Mark one read. |
| `POST` | `/api/_notifications/read-all` | Mark all read. |
| `DELETE` | `/api/_notifications/{id}` | Delete one. |

New notifications push over SSE/WebSocket to the target user.

**Jobs** (async flows, `mode: async`):

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/_jobs/{id}/status` | Poll an async flow: `{job_id, flow_name, status, error?, started_at?, completed_at?}`. |

Async flows enqueue onto the `_benmore_jobs` worker and return `202` +
`{job_id, status_url}` immediately (dodges the 30s edge timeout).

**Audit, aggregates, and other system reads:**

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/_audit?table=&row_id=&user_id=&action=` | Mutation audit trail (admin only). |
| `GET` | `/api/_aggregates` | Materialized aggregate values (also `{{agg.name}}` in templates). |
| `POST` | `/api/_custom_fields` | Add runtime columns without a migration. |
| `GET` | `/api/_usage` | Per-user / per-scope usage + metering. |
| `POST` | `/api/_devices` | Register a push-notification token. |
| `GET` | `/api/_docs` | Auto-generated API docs (JSON); HTML at `/docs`. |

**Broadcast** (Cloudflare SFU, 1:N livestream — `bm.broadcast`):

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/_broadcast/publish` | Proxy publisher SDP exchange to CF (APP_TOKEN stays server-side). |
| `POST` | `/api/_broadcast/subscribe` | Proxy subscriber SDP exchange. |
| `POST` | `/api/_broadcast/stop` | End a broadcast. |
| `GET` | `/api/_broadcast/stats/{slug}` | Live stats for a broadcast slug. |

### Real-time

| Path | Protocol | Notes |
|---|---|---|
| `GET /sse/events` | Server-Sent Events | Scoped by group/user. Payload is always `{table, action}`; the client re-fetches the row. `access.read: anon\|everyone` broadcasts unscoped with full row details. |
| `GET /ws` | WebSocket (stdlib RFC 6455, zero deps) | Bidirectional; table subscriptions + rooms + notification push. `features.ws_anonymous: true` (no `groups:`) shares the `app:<room>` bucket for public broadcast. |

Horizontal scaling: SSE/WS events publish to `_benmore_events` (SQLite pub/sub)
and are polled by every instance in cluster mode.

### PDF

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/pdf/{page}` | Render any app page to PDF server-side (no headless browser). |

Auto-served vendored libraries (no CDN dependency) live under `/_internal/*`
(e.g. `/_internal/tailwind.js`, `/_internal/htmx.js`, `/_internal/bm.js`).

## 2. Control-plane API (`/api/v1`)

The versioned REST contract for managing apps. Defined in `../../api/openapi.yaml`
(OpenAPI 3.1). Base URL: `https://benmore.ai/api/v1`.

> **Status:** this is the durable contract / source of truth from which SDKs and
> the MCP adapter are generated. Per `../../api/README.md`, wiring the Go
> handlers is a planned next step — do not assume these endpoints are live yet.
> For programmatic control-plane access today, use the MCP server.

### Conventions

- **Versioning** — in the path (`/api/v1/...`). Breaking changes → `/v2`.
- **Auth** — `Authorization: Bearer <token>`; tokens from `https://benmore.ai/settings/tokens`. Tokens are scoped to apps the user can access; touching an out-of-scope app returns `403`.
- **operationId** — `snake_case` `verb_object` (`list_apps`, `restore_app_version`). SDK generators and the MCP diff both depend on this.
- **Errors** — `application/problem+json` (RFC 9457) with Benmore extensions `field`, `suggested_fix`, `suggested_alternatives` (see §3).
- **Pagination** — cursor-based. Responses carry `pagination.next_url`; follow it rather than reasoning about cursors. `Cursor` (`?cursor=`) and `Limit` (`?limit=`, default 50, max 500) parameters.
- **Idempotency** — `Idempotency-Key` header (v4 UUID) on `POST`/`DELETE`; cached 7 days, identical replay returns the original response.
- **Concurrency** — mutable resources return ETags; send `If-Match: "<etag>"` on mutating calls to avoid clobbering concurrent edits (`409`/`412` on mismatch).
- **Rate limits** — per-API-key; `RateLimit-Limit`, `RateLimit-Remaining`, `RateLimit-Reset` response headers (IETF draft).

### `x-benmore-mcp` extension

Each operation carries a custom extension describing how it surfaces in the MCP
server, used to keep curated MCP tools and REST ops in parity:

```yaml
x-benmore-mcp:
  tool_name: describe       # which MCP tool handles this (often a composer)
  group: apps               # grouping for toolset selection
  safe_for_agents: true     # false = withheld from auto-agent workflows (destructive/billing)
```

### Operation reference

All 14 operations defined in the spec. `safe` = `x-benmore-mcp.safe_for_agents`.

| operationId | Method | Path | Summary | MCP tool / group | safe |
|---|---|---|---|---|---|
| `list_apps` | `GET` | `/apps` | List apps owned by or shared with the user. | `describe` / apps | yes |
| `create_app` | `POST` | `/apps` | Create a new app. | `create_app` / apps | yes |
| `get_app` | `GET` | `/apps/{app_id}` | Retrieve a single app. | `describe` / apps | yes |
| `delete_app` | `DELETE` | `/apps/{app_id}` | Delete an app. | — / — | **no** (destructive; confirm via MCP apply with consent) |
| `list_branches` | `GET` | `/apps/{app_id}/branches` | List branches for an app. | `describe` / branches | yes |
| `create_branch` | `POST` | `/apps/{app_id}/branches` | Create a new draft branch. | `create_branch` / branches | yes |
| `delete_branch` | `DELETE` | `/apps/{app_id}/branches/{branch}` | Delete a branch. | — / — | **no** |
| `merge_branch` | `POST` | `/apps/{app_id}/branches/{branch}/merge` | Merge a branch into another (usually prod). | `merge_branch` / deploys | yes |
| `list_versions` | `GET` | `/apps/{app_id}/versions` | List commits for a branch. | `describe` / versions | yes |
| `restore_app_version` | `POST` | `/apps/{app_id}/versions/{sha}/restore` | Revert a branch to a prior commit. | `revert_branch` / versions | **no** |
| `list_env` | `GET` | `/apps/{app_id}/env` | List env var keys (values masked). | `describe` / env | yes |
| `set_env` | `PUT` | `/apps/{app_id}/env/{key}` | Set an environment variable. | `set_env` / env | yes |
| `unset_env` | `DELETE` | `/apps/{app_id}/env/{key}` | Remove an environment variable. | `unset_env` / env | yes |
| `get_app_logs` | `GET` | `/apps/{app_id}/logs` | Stream runtime logs for an app. | `logs` / logs | yes |

**Key parameters & bodies:**

- Path: `app_id` (subdomain or internal id), `branch`, `sha`, `key`.
- Shared query params: `cursor`, `limit` (default 50, max 500).
- Shared headers: `Idempotency-Key` (UUID), `If-Match` (ETag).
- `list_apps` query: `status`, `role`. `get_app_logs` query: `since`, `limit`, `level`.
- `create_app` body (`AppCreate`, required): `subdomain` (`^[a-z][a-z0-9-]{2,29}$`, required), `template` (`blank`\|`crm`\|`todo`\|`weather-ops`, default `blank`).
- `set_env` body: required JSON value for the variable.
- `merge_branch` / `restore_app_version` bodies: optional JSON.

**Response shapes** (component schemas):

| Schema | Returned by | Key fields |
|---|---|---|
| `App` | `list_apps`, `get_app`, `create_app` | `id`, `subdomain`, `created_at` (required); `has_prod`, `has_draft`, `url`, `role` (owner\|editor\|viewer), `custom_domain`, `custom_domain_verified`, `_links`. |
| `Branch` | `list_branches` | `name`, `parent`, `head_sha`, `file_count`, `last_commit_at`, `is_locked`. |
| `Version` | `list_versions` | `sha`, `author`, `message`, `committed_at`, `files_changed`. |
| `LogEntry` | `get_app_logs` | `timestamp`, `level` (debug\|info\|warn\|error), `message`, `app`, `request_id`. |
| `Pagination` | list responses (`pagination` field) | `next_url`, `has_more`, `total` (only when counting is cheap). |

Typical status codes: `200`/`201`/`204` success; `400` bad request; `401`
unauthorized; `404` not found; `409` conflict (idempotency / `If-Match`
mismatch / merge conflict).

## 3. Error format (RFC 9457 problem+json)

Both surfaces return errors as `application/problem+json` (the `Problem`
schema). Required: `type`, `title`, `status`. Optional standard: `detail`,
`instance`. Benmore extensions: `field` (offending field), `suggested_fix`
(recovery action), `suggested_alternatives` (alternative values on conflict).
`additionalProperties` is allowed.

```json
{
  "type": "https://benmore.ai/problems/subdomain-taken",
  "title": "Subdomain already in use",
  "status": 409,
  "detail": "The subdomain 'weather-ops' is taken by another app.",
  "instance": "/api/v1/apps",
  "field": "subdomain",
  "suggested_fix": "Choose a different subdomain or pick one of the alternatives.",
  "suggested_alternatives": ["weather-ops-2", "weather-ops-prod", "weatherops"]
}
```
