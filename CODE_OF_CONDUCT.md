# Code of Conduct

## Our standard

This project is committed to a welcoming, harassment-free experience for
everyone who participates — in issues, pull requests, discussions, and any
other project space.

We adopt the **[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**, version 2.1, as our code of conduct.
Please read it; the short version is: be respectful, assume good faith, accept
constructive feedback gracefully, and focus on what's best for the community.
Behavior that the Covenant identifies as unacceptable is not tolerated here.

## Scope

This applies within all project spaces and when an individual is representing
the project in public.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
maintainers at **conduct@benmore.tech**. Reports will be reviewed and handled
confidentially. Maintainers are responsible for clarifying standards and may
take appropriate, fair corrective action in response to any behavior they deem
inappropriate, up to and including a temporary or permanent ban from project
spaces.

For the full text of the standards, enforcement guidelines, and attribution,
see the linked Contributor Covenant 2.1.
